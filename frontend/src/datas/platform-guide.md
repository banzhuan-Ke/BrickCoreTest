# BrickCore 平台使用指南

> 由「使用帮助」整理，可在文档中心发布为团队文档。作者：搬砖柯 · 平台：BrickCore

## 快速开始

欢迎使用 BrickCore！本平台支持 **Web UI 自动化**、**接口自动化**、**性能测试** 和 **AI 自动化测试** 四大能力。

### UI 自动化流程

1. 创建项目 → 管理测试项目
2. 配置环境 → 设置测试网址
3. 安装执行器 → 设备管理下载 zip，登录后上线
4. 编写用例 → 录制测试步骤；编辑页每步可「调试到此步」
5. 执行测试 → 选择在线设备，查看结果

### 接口自动化流程

1. 创建项目 → 配置环境（基础 URL、全局变量）
2. 导入接口 → Swagger/Postman 或手动创建
3. 编写用例 → 请求、断言、变量提取
4. 组建套件 → 测试计划 → 执行记录与报告

### AI 测试（推荐）

1. **AI 模型配置** → 添加文本模型；含图 PRD 另配 Vision 模型
2. **需求用例生成** → 上传 PDF/Word，按章节生成
3. **测试分析** → 测试点、方案、从测试点生成功能用例
4. **功能用例库** → 长期资产；可转 UI/接口自动化

### 平台助手（小测）

右下角 **小测 · 平台助手**：自然语言查数、预览后确认执行套件/计划等（需 `ai_test:view`）。
