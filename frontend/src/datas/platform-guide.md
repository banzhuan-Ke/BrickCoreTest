# BrickCore 平台使用指南

> 由「使用帮助」整理，可在文档中心发布为团队文档。作者：搬砖柯 · 平台：BrickCore

## 快速开始

欢迎使用 BrickCore！本平台支持 **Web UI 自动化**、**App 自动化**、**接口自动化**、**性能测试** 和 **AI 自动化测试** 五大能力。

### Web 自动化流程

1. 创建项目 → 管理测试项目
2. 配置环境 → 设置测试网址
3. 安装执行器 → 设备管理下载 zip，登录后上线
4. 编写用例 → 录制测试步骤；编辑页每步可「调试到此步」
5. 执行测试 → 选择在线设备，查看结果

### App 自动化流程

1. **执行器 + Android 设备** → 共用 BrickCoreRunner；真机 USB / WiFi 无线调试 / 模拟器（MuMu 等）均可，详见执行器安装指南
2. **元素探查 / 元素库** → 原生控件、H5 DOM、图像模板
3. **编写用例** → 选择驱动模式（hybrid / hybrid_web / mobile_chrome / vision 等）
4. **套件 / 计划** → 组合执行，可选录屏
5. **执行记录** → 完整报告、步骤分布、图像相似度、导出 HTML

详见文档中心 **App 自动化** 章节。

### 接口自动化流程

1. 创建项目 → 配置环境（基础 URL、全局变量）
2. 导入接口 → Swagger/Postman 或手动创建
3. 编写用例 → 请求、断言、变量提取
4. 组建套件 → 测试计划 → 执行记录与报告

### AI 测试（推荐）

1. **AI 模型配置** → 添加文本模型；含图 PRD 另配 Vision 模型
2. **需求测试中心**（`/ai-testing`）→ 上传 PDF/Word，进入工作台
3. **Tab「需求文档」** → 章节树勾选范围（全选/清空/**选未覆盖**）→ 加入队列批量生成或单批生成；**章节覆盖检查**查看已覆盖/未覆盖节数
4. **Tab「测试点/方案」** → AI 生成测试点、导入 XMind、生成方案
5. **Tab「功能用例」** → 编辑、导出禅道、复制到 **功能用例库**（长期资产；可转 UI/接口自动化）

补缺口：首轮分批生成后，点 **选未覆盖** → 入队 → 对该批 **补充**（追加用例，不删旧数据）。

### 平台助手（小测）

右下角 **小测 · 平台助手**：自然语言查数、预览后确认执行套件/计划等（需 `ai_test:view`）。
