UI 录制与 AI 优化

Runner 弹出浏览器手动操作，停止录制后由 AI 精简冗余步骤、补全描述，并可勾选补充断言。适合固定业务流程。

UI Agent（MCP）生成步骤

按自然语言描述，由 Agent 逐步读取页面无障碍树、规划并执行操作，固化为一组 Playwright 步骤。适合探索性摸底，固定流程更推荐上一节「录制」。
