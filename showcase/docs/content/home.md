# BrickCore 使用文档

欢迎使用 **BrickCore** 一体化自动化测试平台（社区版）。本文档按菜单结构说明各功能的操作步骤与常见问题。

## 平台能做什么

| 模块 | 用途 |
|------|------|
| UI 自动化 | Web 用例编排、录制回放、计划执行（需 **BrickCoreRunner** 安装包） |
| 接口自动化 | 接口管理、用例/套件/计划、Mock、定时执行、数据工厂 |
| 性能测试 | HTTP 压测、分布式 Worker、报告对比 |
| AI 测试 | 需求生成功能用例、测试分析、失败分析、平台助手 |
| MCP 外部接入 | Kimi Code、Cursor 等 AI 客户端远程查询平台 |
| 数据看板 | 执行趋势、失败统计、定时任务待办 |

## 登录与顶部操作

1. 打开平台地址登录。**在线演示**：[http://43.142.83.156/](http://43.142.83.156/)（账号见演示站说明）
2. 顶部 **选择项目**：用例、接口、AI 数据归属当前项目
3. 顶部 **选择测试环境**（部分页面）：执行时可覆盖
4. 左侧菜单按业务分组展开

> 若看不到某菜单，请联系管理员在 **系统管理 → 角色权限** 中分配权限。

## 执行器（UI 自动化必备）

社区版 Git **不包含** Playwright 引擎源码。请：

1. 从 [Gitee Releases](https://gitee.com/BanZhuanKeOrz/BrickCore/releases) 或平台 **设备管理** 下载 `BrickCoreRunner.zip`
2. 解压后运行 `BrickCoreRunner.exe`，登录并 **上线** 设备
3. 详见 [执行器使用说明](#runner-client)、[执行器获取与发布](#runner-packaging)

## 建议使用顺序

| 步骤 | 做什么 | 文档章节 |
|------|--------|----------|
| 1 | 了解菜单与流程 | 平台概览 |
| 2 | 创建项目、环境、测试目录 | 项目与环境、测试目录 |
| 3 | 安装执行器（做 UI 时） | 执行器使用说明 |
| 4 | 进入 UI / 接口 / AI / 性能 | 功能模块 |
| 5 | 配置报告推送（可选） | 系统管理 |
