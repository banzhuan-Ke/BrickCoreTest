# 系统管理

本章面向 **管理员** 与 **测试负责人**，说明账号、权限、通知与 MCP 等平台级配置。

## 用户管理

**路径**：**系统管理 → 用户管理**

| 操作 | 说明 |
|------|------|
| 新建用户 | 用户名、密码、昵称、邮箱、手机等 |
| 分配角色 | 决定可见菜单与按钮权限 |
| 启用/停用 | 停用后无法登录，历史数据保留 |

## 角色权限

**路径**：**系统管理 → 角色权限**

勾选 **菜单权限** 与 **操作权限**。用户保存角色后建议 **重新登录** 使菜单生效。

## 操作日志

**路径**：**系统管理 → 操作日志**

按操作人、所属模块、时间筛选，用于审计与问题追溯。

## SMTP配置

**路径**：**系统管理 → SMTP配置**

配置发件服务器后，方可在 **通知配置** 中使用邮件渠道。

## 执行器发布

**路径**：**系统管理 → 执行器发布**（需 `device:edit`）

配置 **BrickCoreRunner** 的网盘/OSS 下载链接（推荐，避免大体积 zip 占满服务器）。

| 配置项 | 说明 |
|--------|------|
| 网盘/OSS 链接 | 百度网盘、阿里云盘、OSS HTTPS 直链等 |
| 按钮文案 | 设备管理页显示的下载按钮名称 |

保存后，**UI 自动化 → 设备管理** 出现 **网盘下载** 入口。获取方式见 [执行器获取与发布](#runner-packaging)。

## 通知配置

**路径**：**系统管理 → 通知配置**

按项目配置邮件、钉钉、企业微信等渠道；可 **测试发送**。发送明细见 **推送记录**。

## MCP配置

**路径**：**系统管理 → MCP配置**

供 Kimi Code、Cursor 等通过 MCP 访问平台。配置 **API Key** 与对外地址后，使用者从 **首页看板** 复制接入 JSON。详见 **MCP 外部接入** 章节。

## 接口文档

**路径**：**系统管理 → 接口文档**

在新窗口打开 Swagger，供研发联调。

## 管理员检查清单

- [ ] 默认密码已修改
- [ ] 角色按最小权限分配
- [ ] SMTP 与通知渠道已测试
- [ ] 执行器下载链接或 Releases 已配置（若使用 UI 自动化）
- [ ] MCP API Key 已设置（若启用外部 AI 接入）
