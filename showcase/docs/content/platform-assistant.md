# 平台内 AI 助手

## 适用场景

登录 BrickCore 后，在任意页面右下角使用 **小测 · 平台助手**（悬浮按钮），用自然语言查询项目、接口、UI/压测执行记录，或在确认后触发测试执行与失败分析。

与 **MCP 外部接入** 共用同一套后端工具；网页内无需配置 MCP，登录即可使用。

## 入口与权限

| 项 | 说明 |
|----|------|
| 入口 | 页面右下角悬浮按钮 → **可拖动 / 可放大浮窗**（不遮挡主页面操作） |
| 助手昵称 | **小测**（平台内 AI 助手） |
| 权限 | 需 `ai_test:view`；写操作另受工具级权限控制 |
| 模型 | 使用场景 `platform_assistant`；可在 **AI 模型配置 → 场景绑定** 指定专用模型 |

## 能做什么？

### 只读查询（示例说法）

| 你想了解 | 可以这样说 |
|----------|------------|
| 项目全貌 | 「总结当前项目完整情况」 |
| 接口域 | 「接口有哪些分类和用例？」「列出接口测试计划」 |
| UI 域 | 「有哪些 UI 测试计划和套件？」 |
| 压测 | 「压测场景和执行记录」「Worker 在线情况」 |
| 需求/用例 | 「有哪些需求文档？」「最近失败用例」 |
| 执行记录 | 「最近接口计划执行结果如何？」 |

### 需确认的操作（preview → 确认卡片）

以下操作会先展示 **影响说明**，点击「确认执行」后才真正执行：

- 执行 **接口测试套件** / **接口测试计划**（执行记录触发方式记为 **小测**）
- 执行 **单条接口用例**（按 `case_id` 或名称 + `env_id`，确认后 **同步返回** HTTP 结果）
- 执行 **单条 Web UI 用例**（按 `case_id` 或名称 + `env_id` + Runner `device_id`）
- 执行 **UI 测试计划** / **Web UI 套件**（需环境 ID + Runner device_id）
- 启动 **压测场景**（需环境 ID）
- 提交 **需求用例 AI 批量生成**
- 对失败记录做 **AI 根因分析**

> 不能跳过 preview 直接执行；确认有效期约 5 分钟。  
> 套件/计划/UI 异步任务：确认后会**自动轮询**，完成时在对话中追加结果摘要（约 10 分钟内）。

### 示例说法

| 场景 | 示例 |
|------|------|
| 在线 Runner | 「有哪些在线 Runner 设备？」 |
| 单条接口用例 | 「执行接口用例 12，环境 1」 |
| 单条 Web UI 用例 | 「执行 Web UI 用例 5，环境 1，设备 xxx」 |
| 查 UI 单条结果 | 「查询 UI 用例执行记录 123」 |

## 界面与排版

- **浮层交互**：打开后为独立图层，可拖动标题栏移动位置、右下角拖拽调整大小、标题栏按钮 **放大/还原**；关闭后不影响当前页面操作
- **Markdown 渲染**：标题、列表、**表格**、代码块、内嵌链接均正常渲染；紧凑排版，减少多余空行
- **假流式**：收到完整回答后前端逐字展示（非 SSE）

## 多会话与搜索

- **新建 / 切换 / 重命名 / 删除** 会话，按项目隔离历史
- **会话标题**：首条用户提问会自动作为标题（替代默认「新对话」），便于在多会话下拉中识别
- 会话列表支持搜索 **标题、预览摘要、消息正文**
- 换浏览器或设备登录后，同一账号同一项目的历史仍在（服务端存储）

## 回答内跳转

助手回答中的 `suite_id=`、`plan_id=`、`api_id=`、`case_id=` 等标识可 **点击跳转** 到对应业务页面。

在当前业务页（如接口计划列表）打开助手时，会自动带上 **页面上下文**，便于理解「当前这个计划」等问题。

## 快捷提问

对话区上方提供预设按钮，如「项目概览」「最近失败」「接口概览」「单条用例」等，点击即可填入输入框。

## 与 MCP 的区别

| 维度 | 平台内助手 | MCP 外部接入 |
|------|------------|--------------|
| 用户 | 测试同学（浏览器） | Kimi / Cursor 等 IDE |
| 配置 | 无需 MCP Key | 需 **MCP配置** 或首页看板复制 JSON |
| 工具范围 | 只读 + preview 白名单 | 完整 MCP 工具集 |
| 流式 | 一次性 JSON 返回 + 前端逐字展示（非 SSE） | Streamable HTTP |

## 常见问题

**Q：提示「助手处理失败」或 500？**  
确认已部署最新 backend；查看日志 `[assistant] chat failed`。常见原因：场景未绑定模型（前往 **场景绑定** Tab 配置或一键套用推荐）。

**Q：提示权限不足？**  
当前账号缺少对应菜单权限（如接口计划查看、执行等）。联系管理员分配角色，或换有权限的账号。

**Q：执行类问题没有出现确认卡片？**  
需明确说出「执行 xxx 计划/套件/用例」；助手会先 preview，再在回复中展示确认区域。

**Q：套件执行后对话里没有最终结果？**  
套件/计划为后台异步执行，确认后仅返回 `record_id`。可说「查接口执行记录 15」或前往 **接口自动化 → 执行记录**（触发方式 **小测**）。

**Q：Web UI 单条用例执行后怎么看结果？**  
确认后返回 `execution_id`，可说「查询 UI 用例执行记录 {id}」；需 Runner 在线且 `device_id` 正确。

**Q：响应较慢？**  
典型 4～10 秒；并行查询多个工具后单次 LLM 整理。超时上限约 300 秒（与 Nginx 360s 对齐）。
