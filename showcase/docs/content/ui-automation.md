# UI 自动化

## 适用场景

Web 界面回归：登录、表单、列表、多步骤业务流程。支持手工编排、Playwright 录制、AI 生成/优化步骤、定时无人值守执行。

## 使用前准备

| 项 | 说明 |
|----|------|
| 项目与环境、测试目录 | 见 **项目与环境**、**测试目录** 章节 |
| 执行器 | Windows **BrickCore 桌面客户端**（设备管理网盘/平台下载） |
| 设备在线 | **UI 自动化 → 设备管理**：可 **网盘/平台下载** 执行器；列表中设备 **在线**；可复制 device_id |

### 设备管理页

- 顶部：**网盘下载** / **平台下载 zip** / 使用说明链接  
- 列表：**客户端版本**、**最后心跳**、复制设备编号  
- 管理员配置网盘：**系统管理 → 执行器发布**

### 安装执行器（Windows）

1. **设备管理** 下载 `BrickCoreRunner.zip` 并解压
2. 运行 `BrickCoreRunner.exe`，使用平台账号登录后点击 **上线**
3. 详见 **执行器使用说明**

## 基本流程

```
用例管理 → 套件管理 → 执行计划 → 定时任务（可选）→ 执行记录
```

## 用例管理

**路径**：**UI 自动化 → 用例管理**

左侧 **测试目录树** 筛选列表；新建/编辑时通过树形下拉选择 **所属目录**。

### 新建用例

点击 **新建**，填写用例名称、级别、所属目录等，进入步骤编辑器。

### 编排步骤

- 左侧 **关键字面板** 按分组展示步骤类型，拖拽到右侧
- 常用类型：打开页面、点击、输入、断言、等待、条件分支（if / elif / else）等
- 每步可配置定位器、超时、截图等

### AI 生成步骤

点击 **AI 生成步骤**，选择模式：

| 模式 | 适用 | 说明 |
|------|------|------|
| **单页面** | 单页表单、列表 | 抓取 DOM 一次生成步骤；可手动「抓取页面元素」 |
| **多轮探索** | 跨页、需登录跳转 | 执行→再抓→再生成，1～10 轮 |
| **Agent（MCP）** | 复杂探索 | 基于无障碍树逐步规划；**生成后建议入库，勿直接用于定时 CI** |

需填写：起始 URL（Agent/探索必填）、测试描述、可选 AI 模型。

### AI 录制步骤

1. 点击 **AI 录制步骤**
2. 选择 **在线 Runner 设备**、起始 URL
3. 本地弹出浏览器，按业务流程操作
4. 停止录制后 **应用步骤**（会替换当前全部步骤）
5. 建议执行一遍，必要时 **AI 优化** 去冗余

### 单用例运行

用例列表点击 **运行**：

| 字段 | 说明 |
|------|------|
| 环境 | 必选 |
| 浏览器 | Chrome / Firefox / Safari |
| 界面/无头 | 有界面便于调试，CI 常用无头 |
| AI 定位器自愈 | 失败时尝试自动修复定位（受项目 AI 配置控制） |
| 设备 | 必选在线 Runner |

## 套件管理

**路径**：**UI 自动化 → 套件管理**

左侧目录树筛选；表格显示 **所属目录**。

1. **新建套件**，从用例列表勾选加入
2. 拖动调整 **执行顺序**（串行）
3. 点击 **运行**：选择环境、浏览器、设备（字段同单用例，含自愈开关）

## 执行计划

**路径**：**UI 自动化 → 执行计划**

左侧目录树筛选。

1. **新建计划**，填写名称、所属目录
2. 从右侧 **套件集** 拖拽套件到计划中并排序
3. **运行**：选环境、浏览器、设备（计划运行 **无** 自愈开关，以项目默认为准）

计划是 **定时任务** 的调度对象。

## 定时任务

**路径**：**UI 自动化 → 定时任务**

| 字段 | 说明 |
|------|------|
| 任务名称 | 便于识别 |
| 测试环境 | 执行时使用的环境 |
| 测试计划 | 关联的执行计划 |
| 执行类型 | **间隔执行**（秒，≥60）/ **固定时间** / **Cron 表达式**（分 时 日 月 周） |
| 启用状态 | 关闭后不再触发 |

Cron 示例：`0 8 * * 1-5` 表示工作日 8:00。

首页看板 **待执行定时任务** 区域会展示 48 小时内将触发的任务。

## 执行记录

**路径**：**UI 自动化 → 执行记录**

- 查看计划级执行状态、耗时、通过率
- 下钻到用例、步骤明细
- 支持 **截图、视频**（若用例开启）
- 失败步骤可使用 **AI 失败分析**

用例/套件列表也可查看单次运行记录。

## 设备管理

**路径**：**UI 自动化 → 设备管理**

| 列 | 说明 |
|----|------|
| 状态 | 离线 / 在线 / 执行中 / 故障 |
| 操作系统 | Windows / Linux / MacOS |

- 仅 **在线** 设备可用于运行与录制
- 执行中可打开 **实时画面** 查看浏览器
- 无在线设备时运行会提示「请先注册设备」

## 使用建议

- 定位优先 **角色、文本、data-testid**，减少纯 XPath 依赖
- 长流程拆多个用例，再放入同一套件
- Agent 模式适合摸底，正式回归用录制或手工稳定步骤
- 页面小改可依赖 **定位器自愈**，大改版仍需人工维护

## 常见问题

**Q：录制按钮灰了？**  
无在线 Runner，请先下载安装执行器并 **上线**，再刷新设备管理。

**Q：步骤执行超时？**  
调大该步超时；检查环境 Host 与网络。

**Q：定时任务没跑？**  
确认任务已启用、计划与环境下拉正确；看 **首页看板** 待执行列表。

**Q：与接口测试的关系？**  
UI 与接口独立模块；登录态若走 HTTP 接口，可在 **接口自动化 → Token 授权** 维护。
