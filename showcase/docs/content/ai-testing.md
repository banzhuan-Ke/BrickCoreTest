# AI 测试

## 适用场景

大模型辅助测试设计：需求→功能用例、测试点/方案、失败根因分析、UI/API 步骤生成、禅道互通。

## 使用前准备

| 项 | 说明 |
|----|------|
| AI 模型配置 | 管理员在 **AI 测试 → AI 模型配置** 配置 API Key、模型名 |
| Vision 模型 | 需求含流程图/原型图时必须配置 |
| 项目 | 顶部已选择目标项目 |

## AI 工作台

**路径**：**AI 测试 → AI 工作台**

建议作为 AI 工作 **起点**，集中展示：

- 需求、测试点、用例数量与 **转化漏斗**
- 进行中的 **批量生成任务** 与进度
- **待办提醒**（如待审核用例、失败待分析）
- 最近需求、最近 AI 记录、最近失败（可一键分析）
- 快捷跳转到各 AI 子功能

## 需求用例生成

**路径**：**AI 测试 → 需求用例生成**

### 上传文档

支持：**PDF、Word（.docx）、TXT、Markdown**。

含图片的文档需配置 **Vision 模型** 用于文档理解。

### 生成流程

1. **上传** 需求文件，等待解析完成
2. 左侧 **章节树** 勾选要生成的范围
3. 选择 **文档理解模型**（含图时）与 **用例生成模型**
4. 配置批次（名称、条数等），点击 **生成**
5. 大文档走 **异步批量**，进度在 AI 工作台查看
6. 在表格中 **编辑、删除、调整** 生成结果
7. **导出禅道 XLSX** 或 **复制到功能用例库**

### 项目级规范

在 **AI 模型配置** 或项目相关设置中可维护禅道字段映射、用例标题模板，保证导出格式统一。

## 测试分析

**路径**：**AI 测试 → 测试分析**

1. 选择或关联一条 **需求**
2. 生成 **测试点** 列表
3. 生成 **测试方案** 文档，可查看 **思维导图**
4. 基于测试点 **批量生成功能用例**
5. 确认后 **复制到功能用例库**

适合评审前快速产出测试设计。

## 功能用例库

**路径**：**AI 测试 → 功能用例库**

### 列表与筛选

按标题、模块、禅道 ID、优先级、来源、导入批次等筛选排序。

### 常用操作

| 操作 | 说明 |
|------|------|
| 新建 / 编辑 | 手工维护用例 |
| 禅道 XLSX 导入 / 导出 | 与禅道流程互通 |
| 重复检验 | 按标题+模块（或含步骤摘要严格模式）找重复 |
| 回滚本批 | 按导入批次撤销 |
| AI 生成 UI | 批量将用例转为 UI 步骤预览后导入 |
| 录制生成 UI | 单条用例通过录制生成 UI 草稿 |

### 转 UI 自动化

选用例 → **AI 生成 UI** 或 **录制生成 UI** → 在 **UI 自动化 → 用例管理** 中继续完善步骤与断言。

状态：未生成 / 生成中 / 已生成 / 已导入。

## AI 模型配置

**路径**：**AI 测试 → AI 模型配置**（通常管理员）

### LLM 模型

| 字段 | 说明 |
|------|------|
| 供应商 | OpenAI、DeepSeek、通义、Claude、自定义等 |
| API Key / Base URL | 按供应商填写 |
| 模型名 | 如 `gpt-4o`、`deepseek-chat` |
| 温度、最大 Token、超时 | 影响生成质量与耗时 |
| 默认 / 启用 | 多条配置时指定默认 |

支持 **测试连接** 验证 Key 有效。

### 执行与自愈

- **定位器自愈**：UI 执行失败时尝试 AI 修复定位
- 可设执行默认开启，并控制用例/套件运行弹窗是否允许覆盖

### 场景绑定

为各 AI 业务场景（助手、用例生成、失败分析、Vision 等）指定默认模型；支持 **一键套用推荐**。

### 提示词模板

按场景（需求生成、失败分析等）编辑 system/user 模板，可测试与流式预览。

## 模型使用情况

**路径**：**AI 测试 → 模型使用情况**

- 汇总卡片：今日 / 近 N 日 Tokens、失败次数、成功率
- **场景 Token 占比** 饼图、**按日调用趋势** 折线/柱状图
- 明细列表按项目、场景、用户筛选；**项目列**自动补全（含失败分析、报告摘要等场景）；CSV 导出

## 平台内 AI 助手

**入口**：任意页面右下角 **小测 · 平台助手**

自然语言查项目/接口/UI/压测数据；执行类操作先 preview 再确认。详见 **[平台内 AI 助手](./platform-assistant.md)**。

## 问答准确性评测

**路径**：**AI 测试 → 问答准确性评测**

对标线下 RAG 550 题评测与 `RAG问答测试总结报告` docx：

1. **下载 550 题 Excel 模板** 并导入评测集（序号、问答目录、多轮、场景类型、标准答案等）
2. **被测 API**：使用 **SSE 流式预设** 或自定义 HTTP/SSE；支持 **接口调试**
3. **执行**：填写**评测名称**；模式：自动（API+评判）/ 仅评判 / 仅拉取；支持 **自动分批**、序号范围、**失败重跑**、请求间隔
4. **执行记录**：状态中文显示；可 **删除** 跑批；**合并导出/合并统计**（按序号去重，非条数相加）；**迭代对比**（2～10 组）
5. **统计报告**：优秀率/良好率/不合格率、场景类型与文件类型分析（对齐 docx）
6. **单题报告 + 人工审核**：通过/驳回/批量通过；单题 **重生成**

评判模型在 **AI 模型配置 → 场景绑定 → 问答准确性评判** 配置；Prompt 为 RAG 评测 v2。

题集字段、跑批模式与报告类型见本章上文各小节说明。

## 外部 AI 客户端（MCP）

通过 **BrickCore MCP Server** 让 Kimi Code、Cursor 等用自然语言查项目、查失败、触发执行（能力逐步扩展）。

- 管理员：**系统管理 → MCP配置**
- 说明：**MCP 外部接入** 章节；JSON 复制：**数据看板 → 首页看板 → BrickCore MCP Server**

## 使用建议

- 所有 AI 生成结果 **人工审核** 后再纳入正式回归
- 含图需求务必配 **Vision**
- Agent 探索模式适合摸底，CI 用稳定录制/编排步骤
- 关注 **首页看板** Token 消耗与生成趋势

## 常见问题

**Q：生成很慢或失败？**  
检查模型配置与网络；大文档用批量任务，勿重复提交。

**Q：导出禅道字段不对？**  
检查项目禅道模板与 AI 配置中的字段映射。

**Q：UI 转完步骤不能跑？**  
到 UI 用例编辑检查定位与环境 URL；必要时录制修正。

**Q：MCP 查不到环境变量？**  
MCP 能力按版本迭代，网页 **环境配置** 中可查看完整全局变量。

**Q：问答评测合并后题数变少？**  
合并按 **题目序号去重**，同一序号多批只保留一条（后一次覆盖前一次），不是 4+2=6 简单相加。
