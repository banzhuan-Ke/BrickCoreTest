# Linux 无头 Runner

BrickCore 执行器以 **Windows 安装包**（`BrickCoreRunner.zip`）为主，适用于 UI 自动化、录制与分布式性能 Worker。

## 推荐方式

1. 准备一台 **Windows 测试机**
2. 从网盘或平台 **设备管理** 下载并解压 `BrickCoreRunner.zip`
3. 运行 `BrickCoreRunner.exe`，配置平台地址并 **上线** 设备

## Linux / CI 环境

若需在 Linux 服务器或 CI 流水线中无头运行，请联系项目维护者获取对应部署方案。
