# 数据工厂

## 适用场景

接口 JSON 断言无法验证「数据是否落库正确」；Web UI 操作后也常需核对数据库状态。**数据工厂**提供：

- **环境级数据源**：按项目 + 环境配置 **MySQL / PostgreSQL / Redis** 连接
- **SQL 模板**：setup（造数）/ teardown（清数）/ query（查询）；**Monaco** 代码编辑
- **库断言**：执行后只读校验（SQL 或 Redis 命令）行数、字段值、存在性
- **套件 Hooks**：接口/UI 套件执行前后自动跑 SQL
- **UI 步骤断言**：用例步骤关键字「**数据库断言**」，穿插在 UI 流程中校验库表
- **工具收藏**：星标收藏常用工具与标签，快捷入口

**路径**：**接口自动化 → 数据工厂**  
**权限**：角色需勾选 `data_factory:view`（查看/测试）、`data_factory:edit`（新建/编辑/删除）

## 密码与安全存储

| 项目 | 说明 |
|------|------|
| **存储方式** | 数据库密码以 **Fernet 对称加密** 写入 `password_encrypted` 字段，**明文不落库** |
| **密钥来源** | 优先 `AI_API_KEY_SECRET` 环境变量；未配置时由 Backend `SECRET_KEY` 派生（与 LLM API Key 等同套加密模块） |
| **接口返回** | 列表/详情仅返回 `has_password: true/false`，**不回传密码明文** |
| **编辑行为** | 编辑时密码框留空表示「不修改」；填写新密码才会更新密文 |
| **测试连接** | 弹窗内「测试连接」**不会先写库**，仅临时用表单密码测连通；**须点「保存」才会持久化** |

> Docker 部署时，MySQL 主机填容器网络名 `mysql`（不是 `127.0.0.1`）；PostgreSQL / Redis 同理填对应服务名。

## 配置数据源

1. 点击 **新建数据源**，选择 **环境**（创建后不可改环境）
2. 选择 **类型**：MySQL（默认）、PostgreSQL、Redis
3. 填写主机、端口、库名/DB Index、用户名、密码
4. 可选：**允许写操作**（setup/teardown 需要写操作时勾选）
5. 点击 **测试连接** 确认连通（可选）
6. 点击 **保存** — 密码加密写入数据库

### 各类型填写说明

| 类型 | 默认端口 | 数据库字段 | 用户名/密码 |
|------|----------|------------|-------------|
| MySQL | 3306 | 库名 | 必填 |
| PostgreSQL | 5432 | 库名 | 必填 |
| Redis | 6379 | **DB Index**（如 `0`） | 可选（无密码可留空） |

列表页 **测试** 使用已保存的密文密码连接，无需再次输入。

### 常见问题

**Q：弹窗测试成功，列表再测失败？**  
测试成功但未点 **保存**，密码未入库。请编辑后重新输入密码并 **保存**。

**Q：编辑时密码框是空的？**  
出于安全，编辑不回显密码。若已配置过（`has_password=true`），留空则不修改；若要改密码，重新输入后保存。

## SQL 模板

**类型**：

| 类型 | 用途 | 写操作 |
|------|------|--------|
| setup | 套件/用例执行前造数 | 需数据源允许写 |
| teardown | 执行后清数 | 需数据源允许写 |
| query | 调试查询 | 只读 |

SQL 支持变量替换：`${{变量名}}`（与接口用例变量语法一致）。编辑区使用 **Monaco** 代码编辑器（语法高亮、固定高度滚动）。

## 库断言

### 接口用例 / 套件

在用例或套件编辑页配置 **数据库断言**：

- MySQL/PostgreSQL：仅允许 **SELECT** 类 SQL
- Redis：只读命令如 `GET key`、`HGET hash field`
- 支持运算符：`equals`、`row_count_equals`、`exists` 等
- 接口用例编辑页可 **调试断言** 后保存

### UI 用例步骤（2026-06）

在 UI 用例步骤编辑器中，从 **断言处理** 分组拖入或添加 **「数据库断言」** 步骤：

1. 选择 **数据源**（可按步骤编辑弹窗顶部「参考环境」筛选）
2. 填写 SQL 或 Redis 命令（支持 **插入变量** / **插入工具**）
3. 配置字段、操作符、期望值
4. 执行时 Runner 调用平台内部 API 连库校验；失败则该步骤（及用例）失败

> UI 步骤库断言需 Runner 配置与 Backend 一致的 `INTERNAL_API_KEY`，且 Runner 版本包含 `kw_db_assert` 关键字。

断言结果写入执行报告；HTML 导出含 **数据工厂 Hooks** 区块。

## 与套件 / 计划联动

### 接口自动化

| 阶段 | 时机 |
|------|------|
| setup SQL | 套件用例循环 **之前** |
| teardown SQL + 套件级断言 | 全部用例 **之后** |
| 用例级库断言 | 单条用例执行 **之后** |

已接入：手动/批量执行、测试计划、定时任务（套件模式）。

### UI 自动化

| 阶段 | 执行位置 |
|------|----------|
| setup SQL | 平台派发 MQ **之前** |
| teardown + 套件断言 | Runner 套件完成后 **回调** Backend |

UI 后置 SQL/断言需 Runner **≥ 1.1.0** 且配置与 Backend 一致的 `INTERNAL_API_KEY`。旧 Runner 不影响基础 UI 执行，仅跳过 teardown/断言。

| UI 能力 | 执行方式 |
|---------|----------|
| 套件 setup SQL | Backend 派发 MQ 前 |
| 套件 teardown + 套件级断言 | Runner 完成后回调 |
| **用例步骤「数据库断言」** | Runner 执行到该步时回调 `/internal/evaluate-assertion` |

## 通用工具与标签引用

除 SQL 工厂外，**通用工具** Tab 提供 **70+ 个**在线工具（原 18 个 + 第二期扩展），按分类浏览：

| 分类 | 示例工具 |
|------|----------|
| 随机工具 | UUID、随机整数/字符串/手机号、随机 IPv4 |
| 编码工具 | Base64、URL、Hex、HTML、Unicode 转义 |
| 加密工具 | MD5、SHA256/384/512、HMAC、AES 加解密 |
| JSON 工具 | 格式化、压缩、JSONPath、对比、键列表 |
| 测试数据 | 中文姓名/地址、邮箱、身份证、银行卡、公司名 |
| 日期时间 | 当前时间戳、格式化、加减、相差天数 |
| 文本处理 | 截取、替换、正则匹配/替换/提取、左填充 |
| 数学运算 | 加减乘除、四舍五入 |
| Cron 工具 | 表达式校验、计算下次执行时间 |
| 条码/二维码 | 二维码 Base64（可预览）、Code128 |

执行后可 **保存为标签**，在接口/Web/性能用例中用 `${{df:标签名}}` 引用。

### 保存标签时的环境

| 选项 | 说明 |
|------|------|
| **当前项目通用（全环境可用）** | 不绑定单一环境；本项目下任意环境执行时都会注入（推荐各环境值相同的标签） |
| **指定环境** | 仅在该环境维度隔离/覆盖；与项目通用标签可同时存在，执行时环境级优先 |

下拉首项即为「当前项目通用」，选过具体环境后也可再切回，无需依赖清空按钮。

### 编辑时插入标签

- **插入变量**：弹出加宽面板，顶部可 **搜索** 项目变量、环境变量、内置变量、数据工厂标签。
- **插入工具**（接口/Web 用例编辑、步骤参数）：一键插入内联工具 `${{dt:...}}`，**无需先保存标签**；见下文 §内联工具。
- **数据工厂标签**：独立弹窗，支持按环境范围筛选与搜索后一键插入 `${{df:标签名}}`。

### 内联工具 `${{dt:...}}`（2026-06 起）

在 **接口用例 / Web 步骤 / 压测关联的接口用例** 中，可直接引用 60+ 通用工具，执行时现场计算。

| 写法 | 含义 |
|------|------|
| ``${{dt:uuid}}`` | 无参工具（UUID 等） |
| ``${{dt:md5\|text=@token}}`` | 对变量 token 做 MD5 |
| ``${{dt:md5\|text="test@163.com"}}`` | 固定值（引号内可含 @、\|、=） |
| ``${{dt:hmac_sha256\|text=@a\|secret="key=1"}}`` | 多参数 |

**一致性**：套件、计划、压测场景、UI 套件串行执行时，**同一表达式只计算一次**（随机类工具同轮结果一致）；带 `@变量` 的工具随变量值变化。

**入口**：编辑区工具栏 **「插入工具」**（与「插入变量」并列；已保存标签仍在「插入变量」里）。

**不支持内联**：`json_compare`、`json_format` 等调试类工具（请在数据工厂页内使用）。

**执行支持**：Backend 接口/压测、`VariableResolver`；UI Runner ≥ 当前版本（`runner/tools/data_tools` 与 Backend 同步）；分布式压测 Worker 使用与 Backend 对齐的变量解析器。

### 工具/标签收藏（2026-06）

| 位置 | 操作 |
|------|------|
| **通用工具** Tab | 工具选择框旁 **星标** 收藏；顶部显示 **常用工具** 快捷入口 |
| **使用记录** Tab | 标签列旁 **星标** 收藏；顶部 **常用标签** 可一键筛选 |

收藏按 **当前登录用户 + 项目** 保存，便于个人常用工具/标签快速访问。

### 使用记录

- **引用** 列展示被哪些用例/接口引用；有引用时不可删除，避免执行缺值。
- **编辑**：可修改 **备注** 与 **生效环境**（项目通用 ↔ 指定环境）；标签名、工具、输出结果不可改。若改环境后与同范围已有标签重名，保存会提示冲突。
- **复制**：操作列「复制」一键复制 `${{df:标签名}}` 引用串到剪贴板。
- **二维码** 等工具执行后可预览图片结果（Base64）。

## 使用建议

1. 每个环境至少配置一个 **默认数据源**（可选勾选「设为环境默认」）
2. 只读校验场景 **不要** 勾选「允许写操作」
3. teardown 模板与 setup 成对维护，避免测试数据残留
4. 复杂造数可拆成多条 setup 模板，按 ID 顺序执行
5. UI 流程中需在操作后立即验库时，用 **步骤级数据库断言**；套件结束统一验库用 **套件级断言**
