# 系统管理

本章面向 **管理员** 与 **测试负责人**，说明账号、权限、通知与 MCP 等平台级配置。

## 用户管理

**路径**：**系统管理 → 用户管理**

| 操作 | 说明 |
|------|------|
| 新建用户 | 用户名、密码、昵称、邮箱、手机等 |
| 分配角色 | 决定可见菜单与按钮权限 |
| 启用/停用 | 停用后无法登录，历史数据保留 |

## 角色权限

**路径**：**系统管理 → 角色权限**

勾选 **菜单权限** 与 **操作权限**。用户保存角色后建议 **重新登录** 使菜单生效。

## 操作日志

**路径**：**系统管理 → 操作日志**

按操作人、所属模块、时间筛选，用于审计与问题追溯。

## SMTP配置

**路径**：**系统管理 → SMTP配置**

配置发件服务器后，方可在 **项目配置 → 项目设置 → 通知渠道** 中使用邮件。

## 执行器发布

**路径**：**系统管理 → 执行器发布**（需 `device:edit`）

配置 **BrickCoreRunner** 的网盘/OSS 下载链接（推荐，避免大体积 zip 占满服务器）。

| 配置项 | 说明 |
|--------|------|
| 网盘/OSS 链接 | 百度网盘、阿里云盘、OSS HTTPS 直链等 |
| 按钮文案 | 设备管理页显示的下载按钮名称 |

保存后，**UI 自动化 → 设备管理** 出现 **网盘下载** 入口。获取方式见 [执行器获取与发布](runner-packaging.md)。

## 通知配置

**路径**：**项目配置 → 项目设置 → 通知渠道**（`notification_config:view/edit`）

锁定当前顶栏项目，配置邮件、钉钉、企业微信、飞书等渠道；可 **测试发送**。发送明细见 **系统管理 → 推送记录**。

| 渠道 | 主要配置 | 典型用途 |
|------|----------|----------|
| **邮件** | 收件人列表（逗号或换行） | 可按 API/Web/压测/App 分别配置 **失败告警**；可勾选对应类型 **执行完成后自动推 HTML 报告** |
| **钉钉** | Webhook、可选加签 Secret | 可按类型配置失败告警 |
| **企业微信** | Webhook | 可按类型配置失败告警 |
| **飞书** | 群机器人 Webhook URL | 可按类型配置失败告警（不支持自动推 HTML 报告附件） |

### 触发规则（摘要）

- **启用状态**：渠道总开关；关闭后该渠道不再发送任何通知
- **失败告警**：与「自动推报告」独立，按 API / Web / 压测 / App 分项；只想手动推报告时可关掉对应告警项
- **Web 计划**：失败只发**计划级**一封告警，不再给计划下每个套件各发一封
- **自动推报告**：仅邮件渠道；需勾选对应开关后，执行完成才会自动发 HTML 报告
- **手动「发送报告」**：弹窗勾选本项目已启用的邮件 / 钉钉 / 企微 / 飞书；邮件附完整 HTML，IM 仅摘要

## MCP配置

**路径**：**系统管理 → MCP配置**

供 Kimi Code、Cursor 等通过 MCP 访问平台。配置 **API Key** 与对外地址后，使用者从 **首页看板** 复制接入 JSON。详见 **MCP 外部接入** 章节。

## 接口文档

**路径**：**系统管理 → 接口文档**

在新窗口打开 Swagger，供研发联调。
