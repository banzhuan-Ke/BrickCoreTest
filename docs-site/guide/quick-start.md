# 平台概览

## 登录与导航

1. 浏览器访问平台地址，输入用户名、密码登录
2. 顶部 **选择项目**（必选）；部分功能还需 **选择测试环境**
3. 左侧菜单按业务域分组，点击菜单项进入功能页
4. 页面内面包屑与标题会标明当前位置

## 完整菜单结构

以下名称与左侧菜单一致，便于对照查找。

### 数据看板

| 菜单 | 说明 |
|------|------|
| **首页看板** | 用例/执行统计、占比图、待执行定时任务、AI 摘要、MCP 接入、资源中心快捷入口 |

**首页看板主要区域**（**数据看板 → 首页看板**）：

| 区域 | 内容 |
|------|------|
| 顶栏筛选 | 项目范围、域（全部/Web/接口/性能）、日期范围 |
| 统计卡片 | 用例数、套件数、成功/失败次数；性能：场景数、QPS、错误率 |
| 占比环图 | 用例资产、执行结果分布 |
| 待执行定时任务 | 48 小时内将触发的 UI/接口/性能定时任务 |
| AI 摘要 | 进行中生成任务、近 7 日 Token、Runner 在线数 |
| MCP 卡片 | 接入地址、一键复制 JSON（见 MCP 外部接入） |
| 资源中心 | 文档中心、入门配置、AI 工作台、设备等快捷入口 |
| 失败 Top / 最近执行 | 失败用例排行、最近 5 条执行记录 |

顶栏可筛选：项目范围、域（全部/Web/接口/性能）、日期范围。

### 项目配置

| 菜单 | 说明 |
|------|------|
| **项目管理** | 创建项目、维护项目级全局变量 |
| **环境配置** | 各环境 Host、环境级全局变量；支持 **复制** 快速基于现有环境创建副本（名称自动加「-副本」后缀，可改 Host/变量后保存） |
| **测试目录** | 统一目录树（UI+接口），资产归类与统计 |

### UI 自动化

| 菜单 | 说明 |
|------|------|
| **用例管理** | 新建/编辑用例，手工编排、AI 生成、AI 录制、**插入步骤片段** |
| **步骤片段** | 可复用步骤块（登录/导航等），用例/套件引用后执行时自动展开 |
| **套件管理** | 组合多个用例，调整顺序 |
| **执行计划** | 将多个套件编排为计划，手动或定时执行 |
| **定时任务** | Cron / 间隔 / 固定时间触发计划 |
| **执行记录** | 计划级执行结果、步骤明细、截图视频 |
| **设备管理** | Runner 在线状态、下载执行器、版本/心跳、实时画面 |

### 接口自动化

| 菜单 | 说明 |
|------|------|
| **接口管理** | 接口定义、导入、在线调试 |
| **用例管理** | 断言、变量提取、脚本 |
| **套件管理** | 多用例顺序执行 |
| **测试计划** | 串行/并行、依赖编排、计划级变量 |
| **定时任务** | 定时跑套件或计划 |
| **执行记录** | 请求响应详情、HTML 报告 |
| **Mock 服务** | 模拟下游接口 |
| **Token 授权** | 统一登录态，用例引用 `${{token}}` |
| **数据工厂** | MySQL/PG/Redis 数据源、SQL 模板、库断言（含 UI 步骤）、**70+ 工具**与收藏、`${{df:xxx}}` / `${{dt:...}}` |

### AI 测试

| 菜单 | 说明 |
|------|------|
| **AI 工作台** | 需求/任务统计、待办、快捷入口 |
| **需求测试中心** | 需求列表、测试点/方案/用例统一工作台、XMind 导入、全局测试点/方案 |
| **功能用例库** | 沉淀、禅道导入导出、转 UI |

### 智能浏览器

## 典型工作流

**接口回归**

```
环境配置 → 导入/新建接口 → 编写用例 →（Token 授权）→ 测试计划 → 手动/定时执行 → 执行记录
```

**UI 自动化**

```
环境配置 → 启动 Runner → 新建用例（录制/编排）→ 套件 → 执行计划 → 执行记录
```

**AI 辅助用例设计**

```
平台配置 → AI 模型（含场景绑定）→ 需求测试中心上传需求 → 工作台生成测试点/用例 → 入库/导出禅道 →（可选）转 UI 自动化
```

**问答准确性评测（知识库 / 问答机器人）**

```
下载 Excel 模板 → 导入评测集 → 配置 SSE 被测 API → 执行评测（可分批）→ 统计/对比报告 → 人工审核
```

**平台助手 / MCP 查数与执行**

```
右下角 **小测** 助手提问 或 首页看板复制 MCP JSON → 自然语言查项目/接口/UI/压测 → preview 确认后执行
```

**性能压测**

```
接口用例就绪 → 新建场景 →（可选）启动 Worker → 执行 → 执行记录对比
```

## 权限说明

- 菜单是否可见由 **角色权限** 控制
- 同一页面内按钮（新建、编辑、执行、删除）也可能单独控权
- 看不到功能时联系管理员，勿共用个人账号
