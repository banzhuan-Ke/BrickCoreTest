# 数据工厂

## 适用场景

接口 JSON 断言无法验证「数据是否落库正确」；Web UI 操作后也常需核对数据库状态。**数据工厂**提供：

- **环境级数据源**：按项目 + 环境配置 **MySQL / PostgreSQL / Redis / Elasticsearch** 连接
- **查询控制台**：以 **数据源** 为主选择（环境自动带出，可按环境筛选）；左侧对象浏览器可看表/索引/Redis key（**不自动加载**，点「刷新」；内网常需先勾选经执行机）；手写 SQL、Redis 或 ES JSON DSL；写操作需二次确认；可另存为 SQL 模板
- **SQL 模板**：setup（造数）/ teardown（清数）/ query（查询）；**Monaco** 代码编辑；调试亦可经执行机
- **库断言**：执行后只读校验（SQL 或 Redis 命令）行数、字段值、存在性
- **套件 Hooks**：接口/UI 套件执行前后自动跑 SQL
- **UI 步骤断言**：用例步骤关键字「**数据库断言**」，穿插在 UI 流程中校验库表
- **工具收藏**：星标收藏常用工具与标签，快捷入口

**路径**：**接口自动化 → 数据工厂**  
**权限**：角色需勾选 `data_factory:view`（查看/测试）、`data_factory:edit`（新建/编辑/删除）

## 密码与安全存储

| 项目 | 说明 |
|------|------|
| **存储方式** | 数据库密码以 **Fernet 对称加密** 写入 `password_encrypted` 字段，**明文不落库** |
| **密钥来源** | 优先 `AI_API_KEY_SECRET` 环境变量；未配置时由 Backend `SECRET_KEY` 派生（与 LLM API Key 等同套加密模块） |
| **接口返回** | 列表/详情仅返回 `has_password: true/false`，**不回传密码明文** |
| **编辑行为** | 编辑时密码框留空表示「不修改」；填写新密码才会更新密文 |
| **测试连接** | 弹窗内「测试连接」**不会先写库**，仅临时用表单密码测连通；**须点「保存」才会持久化** |

> Docker 部署时，MySQL 主机填容器网络名 `mysql`（不是 `127.0.0.1`）；PostgreSQL / Redis 同理填对应服务名。

## 配置数据源

1. 点击 **新建数据源**，选择 **环境**（创建后不可改环境）
2. 选择 **类型**：MySQL（默认）、PostgreSQL、Redis、Elasticsearch
3. 填写主机、端口、库名/DB Index/默认索引、用户名、密码（ES/Redis 认证可选）
4. 可选：**允许写操作**（setup/teardown 需要写操作时勾选）
5. 点击 **测试连接** 确认连通（可选）。若平台服务器访问不到该主机（如内网 ES），勾选 **经执行机连接**，选择一台在线空闲压测执行机（引擎 **≥ 1.8.2**）由本机代连；选定后失败不会静默改回平台直连
6. 点击 **保存** — 密码加密写入数据库

### 经执行机测连 / 查询（网络隔离）

与接口「经执行机发送」类似：公网平台打不到内网 MySQL/PG/Redis/ES，而本机压测执行机可达时：

| 入口 | 操作 |
|------|------|
| 数据源弹窗 | 勾选 **经执行机连接** → **测试连接** |
| 查询控制台 | 勾选 **经执行机执行** → 再点左侧 **刷新**（加载目录）或 **执行** |
| SQL 模板 | 勾选 **调试经执行机** → **调试** |

要求：BrickCorePerf / Runner 压测角色引擎 **≥ 1.8.2**；任务类型 `df_datasource_probe`。编排、写确认、变量替换仍在平台；连库 I/O 在执行机。**接口套件** setup / teardown / 库断言（含整包 finalize）与所选 `worker_id` 一致。**UI/App** 步骤 `kw_db_assert`、套件前后 SQL，以及小测 `query_datasource`：环境配置了 **默认接口执行机** 时走该执行机，失败不改回平台本机；未配置则仍由平台直连。查询控制台会预填同一台默认执行机，仍可改。

### 各类型填写说明

| 类型 | 默认端口 | 数据库字段 | 用户名/密码 |
|------|----------|------------|-------------|
| MySQL | 3306 | 库名 | 必填 |
| PostgreSQL | 5432 | 库名 | 必填 |
| Redis | 6379 | **DB Index**（如 `0`） | 可选（无密码可留空） |
| Elasticsearch | 9200 | **默认索引**（如 `logs-*` / `_all`） | Basic Auth 可选；主机可填 `https://host`；自签可用 `insecure:host` |

列表页 **测试** 使用已保存的密文密码连接，无需再次输入。

### 常见问题

**Q：弹窗测试成功，列表再测失败？**  
测试成功但未点 **保存**，密码未入库。请编辑后重新输入密码并 **保存**。

**Q：编辑时密码框是空的？**  
出于安全，编辑不回显密码。若已配置过（`has_password=true`），留空则不修改；若要改密码，重新输入后保存。

## SQL 模板

在配置好数据源后，可在 **SQL 模板** Tab 维护可复用语句；也可在 **查询控制台** Tab 手写执行后「另存为模板」。

### 查询控制台

1. 打开数据工厂 → **查询控制台**
2. 选择 **数据源**（选项含名称 · 类型 · 环境；环境会自动带出）。数据源很多时可选用「按环境筛选」
3. 左侧 **对象浏览器**（**进入页 / 切换数据源不会自动查库**，避免内网源超时）：
   - 需要看表/索引时：内网库先勾选 **经执行机执行**，再点左侧 **刷新**
   - **MySQL / PostgreSQL**：表/视图列表；展开看列；可填入 **索引**、**建表语句**、**EXPLAIN**；双击表名生成 `SELECT … LIMIT 20`
   - **Elasticsearch**：索引列表（文档数/体积）。左侧一次只画出一部分，滑到底继续加载；集群超过 500 个索引时，筛选框输入名字后回车或点刷新，会按名字向 ES 查询。展开看字段；**样例文档** 取 1 条预览并填入 `size:1` 查询；双击索引生成 `_search`
   - **Redis**：按前缀 **SCAN**（勿用 `KEYS *`）；双击 key 按类型填 `GET` / `HGETALL` / `LRANGE` 等
4. 右侧编辑器：MySQL/PG 用 SQL；Redis 用命令文本；ES 用 JSON DSL 或 `METHOD path`
5. 点 **执行**：读查询出结果表；写操作会弹出确认（数据源须开启「允许写操作」）
6. 结果区可 **单击单元格复制**、**复制表格**、**导出 CSV**；成功语句会进入本机 **语句历史**（按数据源记住最近若干条）
7. 平台访问不到数据源时，勾选 **经执行机执行**（引擎 ≥ 1.8.2）后再 **刷新目录** 或 **执行**
8. 需要复用时点 **另存为模板**（默认类型 `query`）

数据源列表支持 **启用 / 停用**；控制台与库断言下拉默认只列已启用源。

小测 / MCP 可用只读工具 `query_datasource` 查库（结果截断进模型，禁止静默写）。数据源所在环境若配置了 **默认接口执行机**（引擎 ≥ 1.8.2），查询经该执行机发出，失败不改回平台本机；未配置则平台直连。也可用技能快捷入口「NL→SQL模板」生成模板后跳转本 Tab 试跑（深链 `?tab=console&datasource_id=`）。

#### 怎么看表（对象浏览器速查）

| 目标 | 操作 |
|------|------|
| 看有哪些表 / 索引 | 选好数据源 →（内网先勾经执行机）→ 点 **刷新** → 左侧列表（一次只画一部分，滑到底再加载）。ES 超过 500 个时，输入名字后回车或再点刷新会向 ES 按名字查；Redis 填前缀后刷新 |
| 看列 / 字段 | 点击 ▸ 展开 |
| 生成只读查询 | 双击表名或索引名（不自动执行） |
| 看索引 / 建表 / 计划 | SQL 源展开后点「索引」「建表语句」「EXPLAIN」 |
| 看 ES 样例 | 展开索引后点「样例文档」 |
| 网络隔离 | 勾选「经执行机执行」后再刷新目录或执行 |

#### Elasticsearch 语句格式

| 写法 | 说明 |
|------|------|
| 纯 JSON | `POST /{默认索引}/_search`，例如 `{"query":{"match_all":{}},"size":20}` |
| `METHOD path` + 可选 body | 如 `GET logs-*/_search` 后跟 JSON；或 `GET logs/_doc/abc` |
| `PING` / `HEALTH` | `GET /_cluster/health`（测活） |

**hits 摊行规则**：每条 hit 一行，含 `_index` / `_id` / `_score`；`_source` 嵌套对象摊成点路径（如 `user.name`）；数组与复杂值序列化为 JSON 字符串。写 API（`_doc` / `_bulk` / `DELETE` 等）默认关闭，需开启「允许写操作」并二次确认。

**类型**：

| 类型 | 用途 | 写操作 |
|------|------|--------|
| setup | 套件/用例执行前造数 | 需数据源允许写 |
| teardown | 执行后清数 | 需数据源允许写 |
| query | 调试查询 | 只读 |

SQL 支持变量替换：`${{变量名}}`（与接口用例变量语法一致）。编辑区使用 **Monaco** 代码编辑器（语法高亮、固定高度滚动）。

## 库断言

### 接口用例 / 套件

在用例或套件编辑页配置 **数据库断言**：

- MySQL/PostgreSQL：仅允许 **SELECT** 类 SQL
- Redis：只读命令如 `GET key`、`HGET hash field`
- 支持运算符：`equals`、`row_count_equals`、`exists` 等
- 接口用例编辑页可 **调试断言** 后保存

### UI 用例步骤（2026-06）

在 UI 用例步骤编辑器中，从 **断言处理** 分组拖入或添加 **「数据库断言」** 步骤：

1. 选择 **数据源**（可按步骤编辑弹窗顶部「参考环境」筛选）
2. 填写 SQL 或 Redis 命令（支持 **插入变量** / **插入工具**）
3. 配置字段、操作符、期望值
4. 执行时 Runner 调用平台内部 API。环境配置了 **默认接口执行机**（引擎 ≥ 1.8.2）时，由该执行机连库，失败不改回平台；未配置则平台直连

> UI 步骤库断言需 Runner 配置与 Backend 一致的 `INTERNAL_API_KEY`，且 Runner 版本包含 `kw_db_assert` 关键字。内网库请在环境里选默认执行机。

断言结果写入执行报告；HTML 导出含 **数据工厂 Hooks** 区块。

## 通用工具与标签引用

除 SQL 工厂外，**通用工具** Tab 提供 **70+ 个**在线工具（原 18 个 + 第二期扩展），按分类浏览：

| 分类 | 示例工具 |
|------|----------|
| 随机工具 | UUID、随机整数/字符串/手机号、随机 IPv4 |
| 编码工具 | Base64、URL、Hex、HTML、Unicode 转义 |
| 加密工具 | MD5、SHA256/384/512、HMAC、AES 加解密 |
| JSON 工具 | 格式化、压缩、JSONPath、对比、键列表；**JSONPath 查询 / 值类型**可点选字段即时预览，过滤表达式仍点「执行」走 jsonpath-ng |
| 测试数据 | 中文姓名/地址、邮箱、身份证、银行卡、公司名 |
| 日期时间 | 当前时间戳、格式化、加减、相差天数 |
| 文本处理 | 截取、替换、正则匹配/替换/提取、左填充 |
| 数学运算 | 加减乘除、四舍五入 |
| Cron 工具 | 表达式校验、计算下次执行时间 |
| 条码/二维码 | 二维码 Base64（可预览）、Code128 |

执行后可 **保存为标签**，在接口/Web/性能用例中用 `${{df:标签名}}` 引用。

接口用例的 **断言 / 变量提取**（以及 Token 授权提取）在填写 JSONPath 时，可点输入框右侧图标打开与「JSONPath 查询」同类的提取工具：左侧粘贴或点选 JSON 字段，右侧预览取值后回填路径。不占用数据工厂编辑权限。

### 保存标签时的环境

| 选项 | 说明 |
|------|------|
| **当前项目通用（全环境可用）** | 不绑定单一环境；本项目下任意环境执行时都会注入（推荐各环境值相同的标签） |
| **指定环境** | 仅在该环境维度隔离/覆盖；与项目通用标签可同时存在，执行时环境级优先 |

下拉首项即为「当前项目通用」，选过具体环境后也可再切回，无需依赖清空按钮。

### 编辑时插入标签

- **插入变量**：弹出加宽面板，顶部可 **搜索** 项目变量、环境变量、内置变量、数据工厂标签。
- **插入工具**（接口/Web 用例编辑、步骤参数）：一键插入内联工具 `${{dt:...}}`，**无需先保存标签**；见下文 §内联工具。
- **数据工厂标签**：独立弹窗，支持按环境范围筛选与搜索后一键插入 `${{df:标签名}}`。

### 内联工具 `${{dt:...}}`（2026-06 起）

在 **接口用例 / Web 步骤 / 压测关联的接口用例** 中，可直接引用 60+ 通用工具，执行时现场计算。

| 写法 | 含义 |
|------|------|
| ``${{dt:uuid}}`` | 无参工具（UUID 等） |
| ``${{dt:now_datetime}}`` | 当前本地日期时间（每次解析取新值） |
| ``${{dt:date_format\|fmt="%Y%m%d%H"}}`` | 按 strftime 格式输出当前时间（日期参数可省略） |
| ``${{dt:md5\|text=@token}}`` | 对变量 token 做 MD5 |
| ``${{dt:md5\|text=@csv.user}}`` | 压测 CSV 列 `user` 做 MD5（与环境变量 `user` 区分；无 CSV 时回退 `@user`） |
| ``${{dt:md5\|text="test@163.com"}}`` | 固定值（引号内可含 @、\|、=） |
| ``${{dt:hmac_sha256\|text=@a\|secret="key=1"}}`` | 多参数 |

**一致性**：套件、计划、压测场景、UI 套件串行执行时，**同一表达式只计算一次**（随机类工具同轮结果一致）；带 `@变量` 的工具随变量值变化。  
**例外**：`now_datetime` / `now_timestamp` / `timestamp_ms`（以及内置 `now_time` / `timestamp`），以及 **`date_format` / `date_add` 在基准日期留空（表示当前时间）时**，**每次解析取新值**，不会被套件级缓存冻住。需要「每次请求当前时间」请用 ``${{dt:now_datetime}}`` 或 ``${{dt:date_format|fmt="..."}}``，不要用已保存的 ``${{df:标签}}``（标签是保存时的快照）。

**入口**：编辑区工具栏 **「插入工具」**（与「插入变量」并列；已保存标签仍在「插入变量」里）。

**库断言「字段」**：取 SQL 结果集中的列名。例如 `SELECT COUNT(*) AS cnt FROM t WHERE id=1`，字段填 `cnt`，再与期望值比较。操作符为「行数等于 / 存在记录」时可忽略字段。

**不支持内联**：`json_compare`、`json_format` 等调试类工具（请在数据工厂页内使用）。

**执行支持**：Backend 接口/压测、`VariableResolver`；UI Runner ≥ 当前版本（`runner/tools/data_tools` 与 Backend 同步）；分布式压测 Worker 使用与 Backend 对齐的变量解析器。

- **引用** 列展示被哪些用例/接口引用；有引用时不可删除，避免执行缺值。

## 文档同步说明

若文档中心显示的内容与最新功能不一致（例如仍写旧版工具数量），通常是因为曾在 **管理文档 → 发布** 中保存过覆盖版本。

**处理方式**（需 `docs:edit` 权限）：

1. **文档中心 → 管理文档 → 从内置源同步**（推荐）
2. 或由管理员在服务器执行内置文档同步脚本（清除 DB 正文覆盖，重新读取内置源文件）

自建部署默认以内置源文件为准；若在文档中心发布过覆盖版本，请按上文同步。

## 使用建议

1. 每个环境至少配置一个 **默认数据源**（可选勾选「设为环境默认」）
2. 只读校验场景 **不要** 勾选「允许写操作」
3. teardown 模板与 setup 成对维护，避免测试数据残留
4. 复杂造数可拆成多条 setup 模板，按 ID 顺序执行
5. UI 流程中需在操作后立即验库时，用 **步骤级数据库断言**；套件结束统一验库用 **套件级断言**
