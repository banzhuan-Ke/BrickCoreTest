# 接口自动化

## 适用场景

HTTP/API 功能与回归测试：单接口调试、多接口串联、复杂业务流程编排、Mock 联调、定时回归。

## 使用前准备

1. 完成 **项目与环境**（Host、全局变量）
2. 在 **项目配置 → 测试目录** 建好目录树，便于侧栏筛选与统计
3. （推荐）在 **Header 模板** 维护公共请求头，编辑接口/用例时一键导入
4. 明确被测 API 的 Base URL 或路径前缀写法
5. 需登录的体系建议先配置 **Token 授权**

## 基本流程

```
接口管理 → 用例管理 → 套件 / 测试计划 → 定时任务（可选）→ 执行记录
```

## 接口管理

**路径**：**接口自动化 → 接口管理**

左侧为 **测试目录树**，点击节点按子树筛选接口列表；顶部可搜索接口名称。

### 新建接口

填写：名称、**所属目录**（树形选择）、HTTP 方法、路径、请求头、Query、Body 等。保存后可被多个用例引用。

**JSON 编辑**：Body、响应 Schema、响应示例等 JSON 文本框支持 **格式化 JSON** / **压缩为一行**（Body 在 JSON 类型下显示）。

**Header 模板**：在 **接口自动化 → Header 模板** 维护公共 Header（如 `Authorization`、`Content-Type`）；编辑接口时在 Headers 区域选择模板并 **从模板导入**（只追加本地没有的 key，不覆盖已有项）。值可写 `${{token}}` 等，执行时按环境变量替换。

### 导入接口

点击 **导入**，三步向导（输入 → 确认 → 完成）：

| 类型 | 支持格式 |
|------|----------|
| **Swagger / OpenAPI** | `.json`、`.yaml`、`.yml` |
| **Postman Collection** | Postman 导出 JSON |
| **Curl** | 粘贴 cURL 命令，可预览编辑 |

导入时可指定 **目标目录**（测试目录树节点），不选则接口暂不归类。

### 关联用例

列表 **关联用例** 列展示引用该接口的用例数量。点击数字打开抽屉，可 **编辑** 用例或 **跳转用例管理**（带 `api_id` 筛选），便于接口变更后批量维护用例。

### 响应示例

编辑接口时可填写 **响应示例**，供 AI 生成断言、一键生成 Schema 参考：

- 支持标准 **JSON**
- 支持 **SSE / 多行原始文本**（如 `event:message` + `data:{...}`）；非 JSON 原样保存
- 一键生成 Schema 会尝试从 SSE 的 `data:` 行解析 JSON 对象
- 编辑页 **测试接口** 成功后可将响应一键写入示例

### 在线调试

选中接口 → **调试** / 编辑页 **发送**：选择环境，发送请求，查看响应（默认超时 **30 秒**），确认路径与鉴权正确后再写用例。

**经执行机发送（网络隔离场景）**：若平台服务器访问不到被测系统，而压测执行机（BrickCorePerf / BrickCoreRunner 压测角色）所在机器可以访问，可在调试弹窗勾选 **经执行机发送**，并选择一台**在线空闲**执行机。平台仍负责变量替换与拼装请求，由执行机代发并回传响应；不勾选时行为与以往一致（由平台本机发送）。执行机引擎需 **≥ 1.0.0**。带文件的 form-data 暂不支持经执行机调试。

接口与用例仍在 **接口自动化** 中维护；性能测试场景继续引用用例，无需在压测模块重复新建接口。

### WebSocket 接口

新建/编辑接口时，协议选择 **WebSocket**：

| 能力 | 说明 |
|------|------|
| 步骤序列 | 配置 connect → send → receive → close 等步骤 |
| 断言 | 可对 receive 步骤的响应内容做断言 |
| 在线调试 | 调试弹窗按步骤执行，查看每步结果 |
| 用例覆盖 | 用例编辑页可覆盖接口默认 WS 步骤 |

路径可写相对路径（拼接环境 Host）或完整 `ws://` / `wss://` 地址。

### form-data 测试文件（2026-06）

接口 **Form Data** 文件字段推荐走平台集中管理，多接口/用例可复用同一文件。

| 能力 | 说明 |
|------|------|
| **路径** | **接口自动化 → 测试文件**（按当前项目隔离） |
| 上传 | 存 MinIO `api-test-files`；支持 pdf、xlsx、证书等 |
| 引用 | 接口编辑、在线调试、用例编辑的 form-data 文件字段 → **选择已上传文件** |
| **关联引用** | 列表展示被哪些接口/用例引用；有引用时 **不可删除** |
| 详情 | 点击「查看全部」可查看完整引用列表 |

历史直传的 `file_key` 仍可执行；重新选择平台文件后纳入项目库便于复用。

## 用例管理

**路径**：**接口自动化 → 用例管理**

左侧目录树筛选；新建/编辑时选择 **所属目录**。

### 用例内容

| 能力 | 说明 |
|------|------|
| 关联接口 | 基于接口定义，可覆盖当次请求参数 |
| Header | 用例配置了 Header 时整表以用例为准（未配置则用接口定义）；支持从 **Header 模板** 导入公共头 |
| 断言 | 状态码、JSON Path、包含文本等 |
| 变量提取 | 从响应写入变量，供后续用例使用 |
| 前置/后置脚本 | Python 脚本，可读写 `variables` 字典 |

变量引用：`${{变量名}}`（双花括号）。

### AI 辅助

用例编辑页可 **根据接口定义 AI 生成** 请求数据与断言初稿，需人工审核。

## 套件管理

**路径**：**接口自动化 → 套件管理**

左侧目录树筛选；表格含 **所属目录** 列。

- 多个用例 **按列表顺序串行** 执行（套件级「并行」开关暂未生效，以串行为准）
- 前一用例 **提取的变量** 自动传给后续用例
- 适合线性流程（登录→查询→提交）
- 添加用例时可按 **优先级 P0～P3** 筛选（与用例管理一致）

运行：选择环境，可选失败是否停止。

## 测试计划

**路径**：**接口自动化 → 测试计划**

左侧目录树筛选；页顶 **汇总卡片** 展示计划数、条目、执行次数、成功率、定时任务等（随目录筛选变化）。表格含 **所属目录**、条目拆分（套件/用例）、最近执行状态。

比套件更灵活，适合复杂编排。

| 配置 | 说明 |
|------|------|
| 执行模式 | **串行** 或 **并行**（并行时各 Item 同时跑） |
| 计划内容 | 左侧添加 **套件** 或 **单用例** 为 Item，右侧排序 |
| 计划级全局变量 | 本计划内所有 Item 共享 |
| 默认环境 | 执行时可覆盖 |

运行弹窗：

- 可选覆盖环境
- **失败停止**：某 Item 失败后是否中止
- **Schema 校验**：按接口定义校验响应结构（若已配置）

点击 **执行** 后任务 **后台异步** 运行，页面轮询状态；可关闭弹窗后在 **执行记录** 查看结果。添加条目时选用例同样支持 **P0～P3** 优先级筛选。

## 数据工厂

**路径**：**接口自动化 → 数据工厂**（详见 **数据工厂** 专章）

用于环境级 **MySQL / PostgreSQL / Redis** 连接、SQL 造数/清数模板、**库断言**（只读校验落库）。

| 能力 | 说明 |
|------|------|
| 数据源 | 按环境配置 MySQL；Docker 部署主机填 `mysql`；**密码 Fernet 加密存储**，接口不回传明文 |
| 保存与测试 | 弹窗「测试连接」**不落库**；须点 **保存** 后列表测试才用已存密码；编辑留空不修改密码 |
| 数据源类型 | MySQL、PostgreSQL、Redis（Redis 用于缓存类断言） |
| SQL 模板 | setup / teardown / query，支持 `${{变量}}`；**Monaco** 编辑；模板/库断言可调试 |
| 套件/用例 | 接口套件、用例编辑页配置 setup/teardown 与库断言 |
| 报告 | HTML 导出含「数据工厂 Hooks」区块 |
| 通用工具 | 70+ 在线工具；保存标签 `${{df:xxx}}` 或内联 `${{dt:...}}`（**插入工具** 按钮） |

套件/计划/定时任务已接入 setup → 用例 → teardown + 断言。UI 套件后置需 Runner **≥1.1.0** 且 `INTERNAL_API_KEY` 与 Backend 一致。内联工具 `${{dt:...}}` 在接口/Web/压测执行时自动计算，详见 **数据工厂** 专章。

## Token 授权

登录态接口统一在 **Token 授权** 维护，用例头里写 `Authorization: Bearer ${{token}}`。详见 **Token 授权** 章节。

## Header 模板

**路径**：**接口自动化 → Header 模板**

| 能力 | 说明 |
|------|------|
| 多模板 | 按项目维护多份 Header 列表，可设 **默认模板** |
| 编辑导入 | 接口/用例/在线调试页选择模板 → **从模板导入**（跳过已存在的 key） |
| 执行行为 | 仅使用接口/用例 **本地 Header**；模板不会自动合并进请求 |
| 变量 | 模板值支持 `${{变量名}}`，与用例内写法一致，执行时按环境替换 |

**变量优先级（同名时后者覆盖前者）：** 项目全局变量 < 环境变量 < 套件前序用例提取 < **Token 授权** < 前置脚本。启用授权后，套件里「登录用例 extract 的 token」**不会**覆盖授权变量——请勿两处同名同时配置，择一即可。

## Mock 服务

**路径**：**接口自动化 → Mock 服务**

| 字段 | 说明 |
|------|------|
| 匹配路径 | 如 `/api/order/detail` |
| 方法 | GET/POST 等 |
| 响应码、Body、延迟 | 模拟下游返回 |
| 高级匹配 | header/query/body 规则，区分同路径多场景 |

调用方式：`{环境或平台地址}/api-module/mock-call/匹配路径`，可加 `?_project_id=项目ID`。

## 定时任务

**路径**：**接口自动化 → 定时任务**

| 字段 | 说明 |
|------|------|
| 执行目标 | **套件** 或 **测试计划** |
| 环境 | 执行环境 |
| 执行类型 | 间隔（≥60 秒）/ 固定时间 / Cron |

支持 **立即执行**、启停、查看最近执行状态。

## 执行记录

**路径**：**接口自动化 → 执行记录**

- 每次执行的套件/计划维度汇总
- 下钻查看单用例：请求、响应、断言、提取变量、耗时
- 导出 **HTML 报告**
- 失败记录 **AI 分析** 根因

## 使用建议

- 登录只配一次 **Token 授权**，业务用例只引用变量（**或** 用套件登录链 + 关闭授权，勿混用同名 `token`）
- 复杂依赖用 **测试计划** 表达并行/串行
- 接口变更后用 **同步检测**（若有）检查关联用例
- Mock 与真实环境切换时注意 Base URL

## 常见问题

**Q：变量传递不到下一用例？**  
确认上一用例提取规则成功；套件/计划顺序正确；变量名拼写一致。

**Q：401 未授权？**  
检查 Token 授权是否启用、刷新成功；用例头是否 `${{token}}`。

**Q：并行计划失败互相影响？**  
并行模式下各 Item 独立，注意不要用会冲突的写操作数据。
