# App 自动化

## 适用场景

Android 设备自动化：原生控件、App 内嵌 H5（WebView）、手机 Chrome H5、**图像模板识别**。支持真机、WiFi 无线调试、Android 模拟器。

平台提供 **用例 / 套件 / 计划 / 元素库 / 元素探查** 等完整编排能力；**真机调度与执行** 需使用勾选 **App 自动化** 的 **BrickCoreRunner** 整包（网盘或设备管理下载，详见 [执行器安装指南](#runner-install-guide)）。

## 使用前准备

| 项 | 说明 |
|----|------|
| 项目 | 顶部选择当前项目 |
| 执行器 | **BrickCoreRunner** 勾选 **App 自动化** 并上线（与 Web 共用客户端） |
| Android 设备 | `adb devices` 为 `device`（USB / WiFi / 模拟器） |
| 权限 | `app_case:view` 等 App 模块权限 |

### Runner 与设备

1. 解压并运行 `BrickCoreRunner.exe`，勾选 **App 自动化**，登录平台并 **上线**
2. 本机 `adb devices` 可见设备；**设备管理** 中查看 `app_udid`
3. 执行用例/计划/元素探查时选择 **在线 App Runner**

详细连接步骤（USB / WiFi / 模拟器）：[执行器安装指南 → App 自动化](#runner-install-guide)。

## 菜单结构

| 菜单 | 说明 |
|------|------|
| **用例管理** | App 步骤编排、调试、单用例运行 |
| **元素库** | 原生 / H5 / 图像模板元素 |
| **元素探查** | 控件树、截图选控件、H5 DOM 探测 |
| **套件管理** | 组合多个 App 用例 |
| **执行计划** | 编排多个套件；支持多设备并行（需 App Runner） |
| **定时任务** | Cron 触发 App 计划 |
| **步骤片段** | 可复用 App 步骤块 |
| **执行记录** | 计划/套件/用例报告、录屏、导出 HTML |

## 基本流程

```
元素库（可选）→ 元素探查 → 用例管理 → 套件管理 → 执行计划 → 执行记录
```

## 驱动模式（摘要）

| 模式 | 适用 |
|------|------|
| **混合（推荐）** | 原生 + 图像模板 |
| **混合 WebView** | App 内嵌 H5 + 原生/图像 |
| **手机 Chrome H5** | 真机 Chrome 页面 |
| **仅控件** | 纯 u2 原生定位 |
| **偏图像** | 以图像识别为主 |

含 H5 定位时须选 **混合 WebView** 或 **手机 Chrome H5**；图像步骤不能选 **仅控件**。

## 与 Web 自动化的区别

| 维度 | Web 自动化 | App 自动化 |
|------|------------|------------|
| 执行引擎 | Playwright + 浏览器 | uiautomator2 + CDP + 图像匹配 |
| 设备 | Runner 上线即可 | Runner 勾选 **App** + adb 设备 |
| 定位 | DOM / 录制 | 元素库、元素探查、图像模板 |
