# 版本更新记录

本文记录 BrickCore 各版本的主要功能变更、问题修复与升级指引。当前平台版本可在页脚查看（**BrickCore v1.6.0**）。

> **说明：** **迭代资料库**通用能力已开放（文件夹、检索、报告向导等）。**定制文档**页签已预留，未开通时请联系管理员进行定制开发。详见 [迭代资料库](./knowledge-base.md)。

## v1.6.0（Web 慢站稳定回放 · 智能点击 · 交互调试与通知增强）

> **适用**：自 **v1.5.x** 升级  
> **平台版本号**：**v1.6.0**  
> **建议执行器**：BrickCoreRunner **v1.6.1**（引擎 **1.6.1**）；客户端最低仍 **≥ 1.3.8**。压测 / 经执行机调试请同步更新 **BrickCorePerf**

> 本版重点：私有部署 / 内网慢站下的 Web 回放稳定性、动作前消歧与容错关键字、执行记录与实时画面、交互调试体验、通知与接口报告可读性。多数行为依赖新执行器，仅升平台不换 Runner 时慢站语义、智能点击、工具条 toast 等不会在执行机生效。

### 概览

v1.6.0 在 v1.5.0 之上累计多项能力，主要包括：

- **慢站执行策略**：超时倍率、导航等待、操作后沉降、忙碌/就绪选择器、遮罩探测、就绪重试；步骤超时与倍率对齐（模板 20s/30s 仍吃倍率，显式超时不乘）
- **动作后等待**：`expected_selector` + `reappear`；失败码可区分遮罩 / 就绪 / 动作超时
- **智能点击 / 智能输入**：动作前本地候选消歧 + 可选后置校验；报告展示候选排名
- **容错关键字**：等待元素可点击；若存在 / 若可见则点击与输入
- **Web 免登录 / 会话保持**：环境「Web 启动登录态注入」；步骤关键字「设置LocalStorage / 设置SessionStorage / 设置Cookie / 设置鉴权Token / 导出登录态」
- **执行记录**：计划/套件进度实时展示；批量删除遵循平台数据保留策略并级联
- **执行器**：MQ 重连后同一套件不去重执行；实时画面推流自愈 + Web 页流；停止与超时预算加固
- **通知**：邮件体积保护；手动发送报告可勾选邮件 / 钉钉 / 企微 / 飞书；SMTP 测试连接；**失败告警按 API/Web/压测/App 分项配置**（与自动推报告独立）；Web 计划失败只发计划级告警
- **接口与数据工厂**：响应 Headers 展示；时间工具每次取新值；库断言数据源与压测分压文案澄清
- **交互调试**：工具条结果同步步骤状态；成功/失败 toast；提取变量回显；页面冻结保留悬停（须 Runner **1.6.1**）
- **压测 CSV**：`${{csv.列名}}` 引用；MD5 等请用 `${{dt:md5|text=@csv.列名}}`（须新执行器）

### 新增功能

- **环境慢站策略**：项目 → 环境管理「Web 慢站执行策略」（默认收起）；保留键写入环境变量但不出现在普通变量列表
- **智能点击 / 智能输入**：同页多匹配时本地打分消歧；分差不足明确失败、不默认点第一个；危险动作须填区域与后置
- **容错关键字**：等待可点击；若存在/若可见则点击、输入（超时内未出现 → 成功跳过）
- **Web 免登录关键字**：设置 LocalStorage / SessionStorage / Cookie / 鉴权Token；导出登录态后可填回环境 `storage_state`；LocalStorage 类须先打开目标域
- **指针拦截自愈**：点击被父级截获时确定性重试 + Heal 可点击校验
- **实时画面**：Web 正式跑 / 交互调试推浏览器页截图；执行机可设 `RUNNER_PAGE_SCREEN_STREAM=0` 回退桌面
- **通知渠道勾选**：手动「发送报告」按项目已启用渠道多选；邮件附完整 HTML，IM 仅摘要
- **失败告警分项**：API / Web / 压测 / App 各自开关，与「自动推报告」独立；Web 计划失败只发计划级一封，避免套件刷屏
- **功能用例库**：未生成 UI 用例时同行可 AI 生成 / 录制生成（需权限）

### 改进优化

- **步骤超时**：新建步骤不再默认写入 20s；保存后从 `config.timeout` 正确回退；运行弹窗可用倍率 **1** 覆盖环境高倍率
- **执行取消**：平台停止后执行机更快收尾；超时类失败跳过用例级重试；禁重试动作一次用满预算
- **邮件报告**：优先失败截图；超软限自动降为无图，避免 SMTP 拒信
- **接口结果**：响应 Headers；导出 HTML 统计卡片可按状态筛选
- **数据工厂**：`now_datetime` 等每次解析取新值；自定义格式用「日期格式化」
- **压测启动弹窗**：列名为「本机上限 / 分压比例 / 本机分到」；单机禁用比例

### 问题修复

- 保存 `timeout=20000` 后实际变成 30000（倍率/回退不一致）
- 下拉「请选择」类占位拦截指针导致自愈难救回
- 长计划 MQ 重连后同一套件被重复执行
- 勾选邮件发送失败却因 IM 成功显示成功
- 交互调试步骤状态被多段合并挡住、API 状态灯竞态

### 升级说明

1. 确认 `PLATFORM_VERSION=1.6.0`
2. 部署 Backend + 重建前端；执行 `aerich upgrade`（若本批有迁移）
3. **必须**更新 **BrickCoreRunner（客户端 1.6.1）** 与引擎 **1.6.1**；压测同步 **BrickCorePerf**
4. 建议环境变量：`RUNNER_CLIENT_VERSION_LATEST=1.6.1`、`RUNNER_ENGINE_VERSION=1.6.1`、`RUNNER_CLIENT_VERSION_MIN=1.3.8`
5. 慢站环境保存一次「慢站执行策略」后冒烟：打开页 → 查询/保存 → 确认倍率与列表刷新不抢跑
6. 压测需在线 Worker；平台不本机代压

**验证**：页脚 **v1.6.0**；环境倍率生效、失败码可见；智能点击 /「若存在则点击」；停止执行数秒内结束；Web 实时画面为当前页；邮件不超软限拒信；交互调试 toast 与变量回显；压测 `${{csv.列}}` / `@csv.列`（新执行器）。

**详见**：[Web 自动化](./ui-automation.md)、[性能测试](./perf-testing.md)、[接口自动化](./api-automation.md)、[亮点功能](./highlights.md)

### 本仓库说明

- 执行器引擎源码不在本仓库；请使用网盘 / 系统管理发布的执行器安装包
- 行业定制报告模板与实现不在本仓库；需联系管理员开通定制开发

## v1.5.0（性能测试可信对比 · Web/接口增强 · 迭代资料库开放）

> **适用**：自 **v1.4.x** 升级  
> **平台版本号**：**v1.5.0**  
> **建议执行器**：BrickCoreRunner **v1.5.3**（引擎 **1.1.1**）；客户端最低仍 **≥ 1.3.8**，引擎最低 **≥ 1.0.0**。压测 / 经执行机调试请同步更新 **BrickCorePerf**

> 本版重点：性能测试准确性与建场景效率、Web/接口体验、执行器增量更新；**迭代资料库**通用能力同步开放（定制文档页签仍需开通）。

### 概览

v1.5.0 累计多项能力，主要包括：

- **性能测试**：真分位 / 基线护栏、**性能验收目标**、梯度与对照报告、SSE 规则与流式开关、CSV 模板、链路与 AI 建场景  
- **Web / 执行器**：失败步骤对齐、交互调试与分层增量更新（客户端 1.5.3）  
- **接口**：Header 整表覆盖、经执行机调试  
- **迭代资料库 / Embedding**：检索、文件夹、模板/变量、通用报告向导；向量 / 混合检索可选  
- **定制文档**：页签预留，默认锁定（联系管理员定制开发）  
- **MCP / 小测**：修复确认执行 UI 用例时身份未注入导致确认失败的问题  

### 新增功能

- **压测准确性**：Ramp-up / Warmup、有效 QPS、多机真分位、对比护栏、场景基线钉选与退化告警、成功专用延迟、多机时钟对齐、用例全量 Avg/Min/Max、权重分压
- **性能验收目标** `perf_targets`：场景配置绝对值门槛（QPS / P95 / 错误率等）；报告确定性 pass/warn/fail；与基线、熔断分离；未配置不展示 AI 自造 SLA
- **增强报告（压测）**：平台报告页对齐导出 HTML——响应时间真分位表与条形图、总请求数核心卡、可信度偏低提示；系统判定与 AI 解读合并展示；多轮 / 梯度对照、HTML / Excel 导出
- **业务链路提效**：接口套件导入 journey、项目级链路模板、接口调试「保存为用例」并可回带追加到压测场景
- **一句话生成压测场景**：自然语言匹配项目内用例/套件生成草稿，确认后落库
- **AI 生成 SSE 解析规则**：粘贴 SSE 样例 + 阶段说明 → `rule_based` 草稿（试解析、不自动落库）；规则支持通用预处理与路径匹配
- **压测引用系统 SSE 配置**：流式配置下拉选用方案，展开为 `stream_profile` 快照
- **梯度 / 对照报告**：阶段明细与分阶段总结；对照红绿语义、中文指标、图表缩放、梯度阶段对照
- **CSV 参数化**：下载模板；选择/删除随场景「保存」落库；上传可 `dry_run` 预览
- **经执行机接口调试**：平台打不到被测系统时，可由在线空闲压测执行机代发（引擎 ≥ 1.0.0；不含文件 form-data）
- **压测 enrichment**：完整下发用例 Header/Params/Body 覆盖，避免仍用接口定义旧值
- **失败步骤对齐**：结果带 `step_id`；编辑页失败提示按 id/指纹对齐
- **交互调试拾取增强**：冻结目标、可配置快捷键、冻结后保持拾取；悬停子元素被父级隐藏时回退祖先
- **执行器分层增量**：正式包产出加密 `.bcpack`（runner / gui）；登录后一键增量更新
- **迭代资料库**：按迭代归档需求/计划/Bug 等；资料检索与问答；输出模板与变量；通用报告向导（迭代/功能/性能报告、测试计划/方案）；生成记录与下载
- **Embedding（可选）**：生成配置中可开启向量 / 混合检索，控制大资料 Prompt 长度

### 改进优化

- **流式开关语义**：关闭「流式问答」清除 `stream_profile`，按普通 HTTP 出报告；仅当次含流式时展示 SSE 阶段；普通 JSON 误走 SSE 有明确提示
- **压测收尾**：优雅 drain、最终报告超时重试与自动 finalize；打开报告避免 MySQL sort buffer 溢出
- **用例 Header**：配置非空时整表以用例为准；为空时仍用接口定义
- **用例 CRUD / 导入导出**：更换关联接口、引用保护（409）、深拷贝与字段补齐
- **交互调试**：工具条关闭浏览器、步骤自动同步、滚动 / 切页 / 步骤库搜索、「从这里开始录制」接录等
- **执行器版本**：Runner 客户端 **1.5.3**；引擎 **1.1.1**（最低引擎 1.0.0）；BrickCorePerf 可移植 venv；正式包纳入 `cryptography`

### 问题修复

- **MCP / 平台助手确认执行 UI**：`confirm_run_ui_case` / `suite` / `task` 直调路由时未注入身份，导致预览成功但确认失败、用例未真正触发；现显式传入 MCP 身份，并将路由业务错误转为可读提示
- **MCP API Key 启动 UI**：无用户 ID 的 API Key 身份可正确通过项目成员校验

### 升级说明

1. 确认 `PLATFORM_VERSION=1.5.0`
2. **必须** `aerich upgrade`（资料库、Embedding、压测基线字段、链路模板、对照报告等）
3. 可选配置 Embedding；可选绑定「一句话建场景 / SSE 解析规则生成」所用模型
4. 重新构建前端；更新 **BrickCorePerf（引擎 1.1.1）** 与 **BrickCoreRunner（客户端 1.5.3）**
5. 建议环境变量：`RUNNER_CLIENT_VERSION_LATEST=1.5.3`、`RUNNER_ENGINE_VERSION=1.1.1`、`RUNNER_ENGINE_VERSION_MIN=1.0.0`
6. 压测需在线 Worker（BrickCoreRunner 压测角色或 BrickCorePerf）；平台不本机代压

**验证**：页脚 **v1.5.0**；压测「套件导入 / 链路模板 / 设为基线 / **验收目标** / 一句话建场景 / SSE 方案 / 关流式无 SSE 区 / CSV 保存落库 / 梯度对照 / 报告分位与目标判定」；用例 Header 覆盖与经执行机调试；Web 失败步骤对齐与冻结拾取；执行器检查更新；**小测 / MCP 确认执行 UI 用例**；资料库文件夹 / 检索 / 通用报告向导可用；定制文档页签可见但未开通时仅提示联系管理员。

**详见**：[性能测试](./perf-testing.md)、[接口自动化](./api-automation.md)、[迭代资料库](./knowledge-base.md)、[亮点功能](./highlights.md)

### 本仓库说明

- 执行器引擎源码不在本仓库；请使用网盘 / 系统管理发布的执行器安装包
- 行业定制报告模板与实现不在本仓库；需联系管理员开通定制开发
- 通用资料库能力已随本版开放；与「定制文档」行业包无关

## v1.4.0（2026-07-18）

> **适用**：自 **v1.3.0 / v1.3.x** 升级  
> **平台版本号**：**v1.4.0**（本版同时纳入交互调试浏览器内操作条等体验补丁）  
> **建议执行器**：BrickCoreRunner **v1.4.5** 及以上  

### 概览

v1.4.0 主要增强 **Web 录制与回放**、**图像模板输入** 与 **第二批 Web 关键字**，完善 **交互调试**（含调试浏览器内操作条）、自愈/AI Act、智能浏览器联动；配置上区分 **平台级** 与 **项目级**，功能用例支持按范围推荐条数与 AI 自定软区间；性能测试侧将压测执行器 **拆分出精简版 BrickCorePerf**，与完整 Runner「压测角色」二选一。

### 新增功能

- **Web 录制增强**：追加/从步骤录制、动态输入值、智能步骤、默认起始 URL、步骤前等待、录制暂停/存变量、步骤红框、定位策略、失败 AI 增强等
- **图像模板输入**：`fill_by_image`，Canvas/自定义输入框兜底
- **Web 关键字扩展（第二批，17 个）**：断言文本不包含/元素数量/文本长度/属性存在与否；等待元素消失、文本变化/稳定、URL 包含、接口响应；滚动到元素、按文本点击、切换最新页；提取响应字段；接受/取消原生弹窗、等待下载
- **点击同屏能力**：`click_ele` / `click_by_text` 支持 `wait_download`，以及 `accept_dialog` / `dismiss_dialog`（可与下载同屏组合）
- **交互调试与多步试跑**、**UI 自愈 / AI Act**、**智能浏览器 → Web 用例**
- **调试浏览器内操作条**（有头调试会话就绪后出现在浏览器底部）：
  - **拾取**：拾取后编辑页可回填（替换某步定位器，或插入新步骤）
  - **高亮 / 取消高亮 / 验证**：按当前选中步骤定位器反馈页面元素
  - **执行本步 / 执行至末尾**：在已打开的调试浏览器中试跑
- **步骤选中**：编辑页点击步骤卡片与操作条「步骤 N」同步；排序用卡片左侧拖拽手柄
- **用户指南**与 HelpContent 录前 checklist
- **项目设置**：菜单 **项目配置 → 项目设置**，按页拆分 **自愈与 AI Act / 录制与调试 / 失败分析 / 功能用例 / 通知渠道**；API：`GET/PUT /sys/project-settings/execution`
- **功能用例条数策略**：按勾选章节推荐参考条数；支持 **AI 自定条数**（软区间）
- **性能测试执行器拆分**：
  - **完整包**：BrickCoreRunner 勾选「压测角色」，可与 Web/App 同机部署
  - **精简版 BrickCorePerf**：仅压测 Worker，体积更小、依赖更少，适合专用压测机 / 多节点横向扩展（含 Windows / macOS 包）
  - 二者 **二选一** 上线即可；平台侧支持分布式 Worker，**不再本机代压**
  - 安装包由网盘 / **系统管理 → 执行器发布** 分发，源码不在本仓库

### 改进优化

- 默认起始 URL 前后端变量替换与校验；`pre_wait_ms` 统一 config 读写并在 AI 优化后保留
- **配置入口分层**：平台配置保留全站项；项目级策略迁入「项目设置」
- **项目设置权限**：`project_settings:view/edit`；通知渠道绑定当前项目
- `wait_for_url_contains` 默认证面子串；独立弹窗/下载步仅对紧随下一步生效
- AI 优化禁止幻觉滚动关键字（须用 `scroll_to_height` / `scroll_to_element`）
- 定位器拾取多候选、iframe 拆分；无定位器步骤执行高亮/验证时给出明确说明

### 问题修复

- smart_step 失败传播、存变量控件值、红框标注黑名单、智能步骤编号拆分等
- **失败分析**：识图改为手动开关；Vision `max_tokens` 超限修复；识图失败降级文本
- **用例编辑页**：最近失败可内联 AI 分析；调试浏览器关闭后会话正确结束
- **执行可靠性**：

v1.1 是一次**以 Web 自动化为主、覆盖平台与执行器全链路**的版本更新。主要方向：

3. **录制与定位体系加固** — 弹窗/iframe/特殊字符定位、AI 自愈、表格隐藏行处理  
4. **执行引擎全面稳定** — 30+ 种步骤关键字统一「优先可见元素」策略  
5. **运行环境与分发** — 无头模式、macOS 安装文档、SPA 页面后退/刷新深度兼容  
6. **协作与数据补齐** — 最后更新人字段、性能列表稳定性

AI 探索 / 录制 Prompt 同步导航步骤说明（后退、提取 URL 等）。

### 七、性能测试

修复执行记录列表 `sort buffer` 溢出；定时压测查询优化。

### 八、执行器分发

客户端 **v1.3.15**；macOS arm64 / Intel 包与安装指南；设备管理升级提示。
