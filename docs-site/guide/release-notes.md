本文记录 BrickCore 各版本的主要功能变更、问题修复与升级指引。当前平台版本可在页脚查看（**BrickCore v1.4.0**）。

## v1.4.0（2026-07-18）

> **适用**：自 **v1.3.0 / v1.3.x** 升级  
> **平台版本号**：**v1.4.0**（本版同时纳入交互调试浏览器内操作条等体验补丁）  
> **建议执行器**：BrickCoreRunner **v1.4.5** 及以上  

### 概览

v1.4.0 主要增强 **Web 录制与回放**、**图像模板输入** 与 **第二批 Web 关键字**，完善 **交互调试**（含调试浏览器内操作条）、自愈/AI Act、智能浏览器联动；配置上区分 **平台级** 与 **项目级**，功能用例支持按范围推荐条数与 AI 自定软区间；性能测试侧将压测执行器 **拆分出精简版 BrickCorePerf**，与完整 Runner「压测角色」二选一。

### 新增功能

- **Web 录制增强**：追加/从步骤录制、动态输入值、智能步骤、默认起始 URL、步骤前等待、录制暂停/存变量、步骤红框、定位策略、失败 AI 增强等
- **图像模板输入**：`fill_by_image`，Canvas/自定义输入框兜底
- **Web 关键字扩展（第二批，17 个）**：断言文本不包含/元素数量/文本长度/属性存在与否；等待元素消失、文本变化/稳定、URL 包含、接口响应；滚动到元素、按文本点击、切换最新页；提取响应字段；接受/取消原生弹窗、等待下载
- **点击同屏能力**：`click_ele` / `click_by_text` 支持 `wait_download`，以及 `accept_dialog` / `dismiss_dialog`（可与下载同屏组合）
- **交互调试与多步试跑**、**UI 自愈 / AI Act**、**智能浏览器 → Web 用例**
- **调试浏览器内操作条**（有头调试会话就绪后出现在浏览器底部）：
  - **拾取**：拾取后编辑页可回填（替换某步定位器，或插入新步骤）
  - **高亮 / 取消高亮 / 验证**：按当前选中步骤定位器反馈页面元素
  - **执行本步 / 执行至末尾**：在已打开的调试浏览器中试跑
- **步骤选中**：编辑页点击步骤卡片与操作条「步骤 N」同步；排序用卡片左侧拖拽手柄
- **用户指南**与 HelpContent 录前 checklist
- **项目设置**：菜单 **项目配置 → 项目设置**，按页拆分 **自愈与 AI Act / 录制与调试 / 失败分析 / 功能用例 / 通知渠道**；API：`GET/PUT /sys/project-settings/execution`
- **功能用例条数策略**：按勾选章节推荐参考条数；支持 **AI 自定条数**（软区间）
- **性能测试执行器拆分**：
  - **完整包**：BrickCoreRunner 勾选「压测角色」，可与 Web/App 同机部署
  - **精简版 BrickCorePerf**：仅压测 Worker，体积更小、依赖更少，适合专用压测机 / 多节点横向扩展（含 Windows / macOS 包）
  - 二者 **二选一** 上线即可；平台侧支持分布式 Worker，**不再本机代压**
  - 安装包由网盘 / **系统管理 → 执行器发布** 分发，源码不在本仓库

### 改进优化

- 默认起始 URL 前后端变量替换与校验；`pre_wait_ms` 统一 config 读写并在 AI 优化后保留
- **配置入口分层**：平台配置保留全站项；项目级策略迁入「项目设置」
- **项目设置权限**：`project_settings:view/edit`；通知渠道绑定当前项目
- `wait_for_url_contains` 默认证面子串；独立弹窗/下载步仅对紧随下一步生效
- AI 优化禁止幻觉滚动关键字（须用 `scroll_to_height` / `scroll_to_element`）
- 定位器拾取多候选、iframe 拆分；无定位器步骤执行高亮/验证时给出明确说明

### 问题修复

- smart_step 失败传播、存变量控件值、红框标注黑名单、智能步骤编号拆分等
- **失败分析**：识图改为手动开关；Vision `max_tokens` 超限修复；识图失败降级文本
- **用例编辑页**：最近失败可内联 AI 分析；调试浏览器关闭后会话正确结束
- **执行可靠性**：
  - UI 停止接口校验项目成员；Runner **MQ 延迟 ACK**；设备占用行锁；长步骤可打断
  - 取消标记 TTL、计划停止同步用例态；`RUNNER_MQ_PREFETCH_COUNT` 可调

### 升级说明

1. 确认 `PLATFORM_VERSION=1.4.0`
2. Runner 升级至 **v1.4.5**（含调试浏览器操作条、MQ 延迟 ACK、长步骤打断、新关键字）
3. `aerich upgrade` + 重新构建前端（`frontend` → `npm run build`）
4. 若使用压测：准备在线 Worker——任选 **BrickCoreRunner（压测角色）** 或精简版 **BrickCorePerf**（Windows / macOS），平台侧不再本机代压

**验证**：页脚 **v1.4.0**；步骤库新关键字可拖入；交互调试至就绪后浏览器底部可见操作条；拾取/高亮/验证可用；项目设置可保存；压测「执行机」可见在线 Worker。

### 本仓库说明

- **迭代资料库**开发测试中，后续放出
- 执行器引擎源码不在本仓库；请使用网盘执行器安装包

## v1.3.0（2026-07-08）

> **适用**：自 **v1.2.0** 升级至 **v1.3.0**  
> **平台版本号**：**v1.3.0**  
> **建议执行器**：BrickCoreRunner **v1.4.0** 及以上（Web）

### 概览

v1.3.0 在 v1.2.0 基础上新增交互调试、智能浏览器增强、平台配置聚合与 Embedding 配置，并更新了文档中心相关说明。

### 新增功能

- **交互调试**：Web 用例编辑页支持先打开浏览器、手动就位、按步试跑、多步调试，以及定位器拾取与回填
- **UI 自愈 / AI Act**：支持步骤 intent、AI Act 兜底、运行弹窗开关，结果可写回用例
- **智能浏览器增强**：AI 优化任务描述、执行记录与 GIF 回放，探索结果可导入 Web 自动化用例
- **Embedding 配置**：支持 Embedding 模型、向量维度、默认项与连通性测试（通用配置）

### 改进优化

- **平台配置入口聚合**：AI 模型、MCP Server、SSE 解析、执行器发布、登录页等统一到「系统管理 → 平台配置」
- **文档中心**：快速开始、智能浏览器、MCP 接入、平台使用帮助等章节已同步

### 问题修复

- **交互调试**：多段结果合并、会话关闭、初始 URL 解析、Runner 回调鉴权、步骤截图等
- **运行体验**：调试提示、AI Act 运行提示等

### 升级说明

1. 确认 `PLATFORM_VERSION=1.3.0`
2. 建议执行器与平台推荐版本对齐
3. 若从 v1.2.x 升级：重新构建前端，并在 **文档中心 → 管理文档 → 从内置源同步** 后核对内容

**验证**：页脚显示 **v1.3.0**；交互调试、UI 自愈 / AI Act 与 Embedding 配置可用。

## v1.2.0（2026-07-04）

> **适用**：自 **v1.1** 升级至 **v1.2.0**（含 v1.1.1 补丁能力）  
> **平台版本号**：**v1.2.0**  
> **建议执行器**：BrickCoreRunner **v1.3.16** 及以上（Web；引擎 **v1.0.2**）

### 概述

v1.2.0 是一次**平台大版本同步**，在 v1.1 基础上纳入 v1.1.1 补丁、Web 稳定性修复，并同步 **App 自动化平台侧**能力（菜单、用例编排、数据模型等）。

### 一、平台通用

**执行报告（v1.1.1）**

- 计划报告统计卡片筛选用例；套件报告「返回计划报告」  
- 跳过筛选修复；报告页快捷跳转编辑用例/套件  

**Web 自动化**

- **插入步骤片段无数据**回归修复（`uiFragmentApi.list` 别名）  
- 录制与 AI 自愈加固（需 Runner **v1.3.16+**）：候选打分、表格行锚定、iframe 前缀、`get_by_role` 解析修复  

**搜索与助手**

- 站内搜索、AI 小助手增强；文档中心链接修复  

### 二、App 自动化（平台侧已同步，真机执行需 AppEngine Runner）

> 升级后可见 **App 自动化** 菜单（用例、元素库、元素探查、套件、计划、定时任务、片段、执行记录）。  
> 数据库迁移 **#100～#104** 会创建 App 相关表结构；**无 AppEngine 时无法完成真机调度与执行**。

| 能力 | 平台编排 | 真机执行 |
|------|----------|----------|
| 用例 / 套件 / 计划 CRUD | ✅ | 需整包 Runner + AppEngine |
| 元素库 / 元素探查 UI | ✅ | 探查/投屏需 AppEngine Runner |
| 计划并行 / 定时任务 / 片段 | ✅ 编排 | 需 AppEngine Runner |
| HTML 报告 / 邮件推送 | ✅ 配置 | 需 AppEngine Runner |

App 完整能力（AI 步骤生成、scrcpy 投屏、录屏加固等）需使用含 AppEngine 的整包 Runner 与对应部署环境。

### 三、升级步骤

```bash
git pull
cd frontend && npm install && npm run build && cd ..
docker compose up -d --build
docker exec -it fastapi_backend aerich upgrade
```

1. 确认 `PLATFORM_VERSION=1.2.0`；Web 场景建议 `RUNNER_CLIENT_VERSION_LATEST=1.3.16`  
2. 下载最新 **BrickCoreRunner** 网盘包并重新上线  
3. 迁移 **#97～#104**（含最后更新人、测试文件夹、App 表等）  

**验证**：页脚 **v1.2.0**；Web「插入片段」有数据；UI 报告筛选正常；Runner ≥ 1.3.16。

### 四、兼容性

| 项 | 说明 |
|----|------|
| 数据库 | 必须 `aerich upgrade`（#97～#104） |
| 执行器 | Web 建议 **v1.3.16+**；App 真机需 **v1.4.0+** 整包（含 AppEngine） |
| 用例数据 | 向前兼容 |

## v1.1（2026-06-23）

> **适用**：自 **v1.0** 升级至 **v1.1**  
> **平台版本号**：**v1.1**  
> **建议执行器**：BrickCoreRunner **v1.3.15** 及以上（引擎 **v1.0.2**）

### 概述

v1.1 是一次**以 Web 自动化为主、覆盖平台与执行器全链路**的版本更新。主要方向：

1. **测试资源管理升级** — 文件夹上传、多文件上传、测试文件管理页重构  
2. **用例编排提效** — 多选生成片段、步骤复制、套件/计划编辑搜索与「已加入」标识  
3. **录制与定位体系加固** — 弹窗/iframe/特殊字符定位、AI 自愈、表格隐藏行处理  
4. **执行引擎全面稳定** — 30+ 种步骤关键字统一「优先可见元素」策略  
5. **运行环境与分发** — 无头模式、macOS 安装文档、SPA 页面后退/刷新深度兼容  
6. **协作与数据补齐** — 最后更新人字段、性能列表稳定性  

### 一、UI 测试资源管理

**测试文件夹（新）**：整目录上传 MinIO、步骤文件夹模式、中文路径与下载还原修复。

**单文件增强**：多文件模式、自定义显示名、多文件选择器。

**管理页重构**：单文件 / 文件夹分 Tab；兼容 `${{files_path}}`；预签名 URL 下载。

### 二、用例编排与套件编辑

- 多选步骤生成可复用 **片段**（可替换为片段引用）  
- 步骤复制、套件编辑 **左右分栏**  
- 计划/套件编辑：**名称搜索** + **「已加入」** 标识  

### 三、列表协作与数据字段

- 用例、套件、计划列表 **最后更新人**（迁移 **#97**）  
- 用例编辑跳转优化  

### 四、UI 录制与定位

弹窗链式定位、特殊字符转 `get_by_text=`、iframe 原生定位、AI 自愈规范化与 **优先可见元素**。

### 五、执行引擎（Runner）稳定性

> 需 **v1.3.15+**。

- 30+ 步骤关键字 **优先可见元素**；点击类失败 `force` 重试  
- SPA：**history.back()** 后退、`domcontentloaded` 刷新、**提取当前页面 url**、`fallback_url`  
- hover：`timeout` 仅定位超时，停留 `wait_time` 默认 500ms  
- 失败步骤报告序号修正；Linux **无头模式**  

### 六、AI 能力

AI 探索 / 录制 Prompt 同步导航步骤说明（后退、提取 URL 等）。

### 七、性能测试

修复执行记录列表 `sort buffer` 溢出；定时压测查询优化。

### 八、执行器分发

客户端 **v1.3.15**；macOS arm64 / Intel 包与安装指南；设备管理升级提示。

### 九、部署与运维

平台版本 **v1.1**；`restart.sh` 分支自适应；迁移 **#97**、**#98**。

### 十、升级步骤

```bash
git pull
cd frontend && npm install && npm run build && cd ..
docker compose up -d --build
docker exec -it fastapi_backend aerich upgrade
```

下载最新 **BrickCoreRunner** 并重新上线；确认 `RUNNER_CLIENT_VERSION_LATEST=1.3.15`。

**验证**：页脚 v1.1、测试文件双 Tab、片段生成、最后更新人、编排「已加入」、Runner ≥ 1.3.15。

### 十一、兼容性

| 项 | 说明 |
|----|------|
| 数据库 | 必须 `aerich upgrade` |
| 执行器 | 建议 **v1.3.15+** |
| 用例数据 | 向前兼容 |

### 十二、使用建议

1. 虚拟列表用语义化定位，避免纯 `(//xpath)[1]`  
2. 悬停菜单：hover → 等待 500~1000ms → click  
3. SPA 无历史时用新标签或 `fallback_url`  
4. macOS 须在 Mac 本机解压对应芯片包
