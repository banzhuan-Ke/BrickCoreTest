# 智能浏览器

**路径**：**AI 测试 → 智能浏览器**  
**权限**：查看 `ai_test:view`；创建/执行/停止/删除 `ai_test:execute`

基于自然语言任务描述的浏览器 Agent：输入起始 URL 与任务描述，由 AI 自动规划并逐步操作网页。适用于**演示、探索型验证、一次性冒烟**（可回归场景请用 **Web UI 自动化 + 录制/Agent**）。

## 功能结构

| 页面 | 说明 |
|------|------|
| **用例库** | 保存场景；编辑执行选项；**AI 优化**任务描述 |
| **执行任务** | 临时执行或从用例加载；实时截图与步骤日志 |
| **执行记录** | 历史任务；停止、重跑、**单条/批量永久删除** |
| **执行报告** | 元数据、步骤明细、步骤截图、结果摘要 |
| **GIF 预览** | 任务回放 GIF（从报告或执行页打开） |

## 使用步骤

### 1. 配置 AI 模型

1. 顶部选择 **项目**
2. **系统管理 → 平台配置 → AI → 场景绑定**：
   - **智能浏览器**（`browser_lab`）：执行任务用的模型
   - **智能浏览器 · 任务描述优化**（`browser_lab_task_optimize`）：改写任务描述（可选）
3. **执行推荐**：优先使用响应较快的模型；DeepSeek 建议 **关闭思考模式** 与 Vision

### 2. 编写用例 / 任务

**任务描述建议**（中文）：

- 写清 **可点击路径**（菜单名、按钮文案、表格行操作）
- 避免模糊表述；列表搜索为模糊匹配，找特定行时写清核对方式
- 登录请用 **参考环境 + `${{password}}`**（明文密码不会写入动作缓存；续跑可能丢失登录态）
- 不确定怎么写：任务描述旁点 **「AI 优化」** → 预览对比 → **采用优化结果**

**示例**：

```text
登录（账号 xxx / 密码 xxx）后，在左侧菜单进入「智能浏览器 → 用例库」，
在表格中找到用例名称为「6」的行并点「编辑」确认。完成后用中文总结。
```

### 3. 执行与查看结果

1. **用例库** 新建/执行，或 **执行任务** 页临时填写后 **开始执行**
2. 执行前会弹出 **确认执行** 对话框：核对任务摘要、执行选项，并选择 **在线执行设备**（配置设备离线时可改选其他 Runner）
3. 右侧 **实时截图** 与步骤日志（**GET 轮询 + 前端增量展示**，减轻平台压力）；运行中可 **停止**
4. 完成后 **查看报告**；有 GIF 时从报告页点击预览
5. **执行选项**（执行任务 / 用例库）：

| 选项 | 说明 |
|------|------|
| **执行设备** | 选择在线 **Web 自动化** Runner；浏览器在该机器上跑，平台只做编排与报告 |
| **浏览器模式** | 默认 **无头**（省资源）；Runner 装在本机 Windows 时可临时选 **有头** 直观调试 |
| **参考环境** | 解析 `${{变量}}`；登录缓存回放按此环境注入账号密码 |
| **Vision 截图理解** | 每步发截图辅助理解；较慢，DeepSeek 自动关闭 |
| **生成回放 GIF** | 任务结束生成 replay.gif |
| **CDP 异常自动续跑** | CDP/截图失败时重启 session（**丢失登录态**） |
| **续跑次数** | 1～5，默认 2 |
| **重复上限** | 2～8，默认 3；同一操作连续 N 步无进展则自动停止 |
| **启用动作缓存** | 同任务二次执行优先零 Token 回放；回放失败可降级 Agent（每任务最多 1 次） |
| **强制刷新缓存** | 忽略已有缓存，强制走 LLM 并覆盖写入 |

> **动作缓存 ≠ CI**：缓存只加速智能浏览器复跑/演示；进计划与定时请用下方「导入 Web 用例」。登录请用 `${{password}}` + 参考环境（明文密码不入库）。用例库可「清缓存」。

5. **执行记录**：重跑、按用例筛选、**勾选批量永久删除**（执行中的须先停止）

### 4. 删除与数据清理

智能浏览器采用 **物理删除**（非逻辑删除）：

| 操作 | 行为 |
|------|------|
| 删除执行记录（单条） | 删除记录及关联截图/GIF |
| 批量删除执行记录 | 勾选多条 → **批量删除**；执行中任务自动跳过 |
| 删除用例 | **永久删除用例** + **级联删除**其下全部执行记录 |

删除前会二次确认，**不可恢复**。

### 5. 保存为用例

临时任务完成后，可在执行页 **保存为用例**，便于团队复用。

### 6. 导入 Web 自动化用例（2026-07）

执行报告页点击 **导入 Web 用例**（需 `ui_case:edit`）。平台提供三条路径，请按场景选择：

| 路径 | 入口 | 产出质量 | 适用 |
|------|------|----------|------|
| **动作缓存回放** | 同任务二次执行（cache HIT） | 步骤来自已固化动作，导入较稳 | 演示复跑后快速落库 |
| **快速转换（草稿）** | 报告 → 导入 Web 用例 | 启发式定位器，需人工核对 | 探索后先落草稿 |
| **Agent 固化** | 报告 → 导入 Web 用例 → Agent 重新固化 | Playwright 级步骤，可回归 | CI / 计划任务 |

**快速转换**流程：

1. 预览由 Browser Lab 步骤转换的 Playwright 步骤列表（弱定位器行会高亮）
2. 填写用例名称，可选是否插入「打开浏览器」
3. 确认后写入 **Web 自动化 → 用例管理**（草稿），并跳转编辑页核对定位器

> **动作缓存 ≠ 导入**：缓存只加速智能浏览器同任务复跑（零 Token）；进计划与定时请走「导入 Web 用例」或 Web 用例 Agent。  
> cache HIT 任务导入时优先使用缓存动作，通常比 step_log 快速转换更可靠。

### 7. 在执行机上跑浏览器（推荐）

智能浏览器、AI 生成用例的 **单页抓取 / 多轮探索 / Agent** 等会打开真实浏览器。为减轻平台服务器压力、加快本地调试反馈，浏览器过程放在 **在线执行机（Runner）** 上运行，平台负责派发、模型调用与报告聚合。

| 好处 | 说明 |
|------|------|
| **减轻服务器压力** | Chromium / browser-use 不占用平台机 CPU/内存，小规格部署更稳 |
| **支持有头模式** | Runner 装在本机 Windows 时可开 **有头**，直观看到每一步操作 |
| **执行更贴近业务网** | 执行机可放在能访问被测系统的网络环境，减少平台机出网限制 |
| **能力开箱可用** | `browser-use` 已随 Runner 依赖 / 正式包一并安装（约 +200MB）；设备页 **工具链** 可查看是否就绪 |

**使用前请确认**：

1. 本机或内网已启动 Runner 客户端，设备管理显示 **在线**，并勾选 **Web 自动化**
2. 系统配置 → MCP → **平台对外地址**（或 env `BASE_URL`）已填，便于执行机回调平台
3. 建议执行器客户端 / 引擎 **≥ 1.6.5**

运维可选环境变量：

| 变量 | 说明 |
|------|------|
| `BROWSER_RUN_DISPATCH_ENABLED` | 默认 `1`；开启后浏览器类任务走执行机派发 |
| `BASE_URL` / MCP「平台对外地址」 | 执行机回调与任务鉴权 |
| `BROWSER_LAB_RUNNER_HEARTBEAT_TIMEOUT` | 执行机心跳超时秒数（默认 120）；长时间无响应将标记任务失败 |

LLM 密钥经平台代理转发，**不会**下发到执行机本地。

## 与 Web 自动化的区别

| | 智能浏览器 | Web UI 用例 Agent |
|--|-----------|-------------------|
| 输入 | 自然语言任务 | 步骤 JSON / 录制 |
| 产出 | 当场跑完 + 记录/报告/GIF | 可保存步骤、Runner 分布式回归 |
| 适用 | 演示、探索、一次性验证 | CI 回归、稳定用例库 |
| 删除 | 执行记录/用例 **物理删除** | 多为逻辑删除 |

## 常见问题

**Q：任务描述怎么写才不容易翻车？**  
用 **AI 优化** 改写；或手写顺序步骤 + 明确按钮文案。

**Q：Agent 反复搜索/点击，浪费 Token？**  
调低 **重复上限** 或优化任务描述；平台会在同一操作连续重复达上限后自动停止。

**Q：DeepSeek 报错 tool_choice？**  
关闭 AI 配置中的 **思考模式**。

**Q：开 Vision 很慢？**  
关 Vision + 写清 DOM 路径；或换更快模型。

**Q：GIF 无法预览？**  
从报告或执行页点击 GIF 链接（须已登录）；勿直接访问静态文件路径。

**Q：删除后能恢复吗？**  
**不能**。执行记录与用例均为物理删除。

**Q：搜索「6」命中多条？**  
用例库搜索为模糊匹配；建议写「在表格中找名称为 6 的行，点编辑确认」。

**Q：提示没有在线执行设备？**  
请启动 Runner 并勾选 **Web 自动化**；确认设备页为「在线」。执行确认弹窗里也可改选其他在线机器。

**Q：用例里配的执行机离线了怎么办？**  
点「执行」后的确认弹窗会提示离线，并可下拉选择其他在线 Runner 完成本次任务（不会自动改写用例里的默认设备，除非你在编辑页保存）。
