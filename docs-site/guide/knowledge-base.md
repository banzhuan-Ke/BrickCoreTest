# 迭代资料库

项目级 **迭代测试资料** 归档与 AI 引用：按版本/迭代保存需求、测试计划、Bug/任务导出、测试总结等；在 **生成用例、失败分析、迭代报告** 等场景中可选引用。

## 已开放能力

| 能力 | 说明 |
|------|------|
| 迭代文件夹 | 按迭代组织需求、计划、Bug 等文档 |
| 资料检索 / 问答 | 关键词检索分块；可选智能回答 |
| 输出模板 / 变量 | 通用 Word 模板与占位符 |
| 报告向导 | 基于资料与执行记录生成通用迭代/功能/性能等报告 |
| 生成记录 | 查看进度与下载 |

资料量大时默认走 **词法分块检索（RAG）** 控制 Prompt 长度；可在生成配置中 **可选开启向量 Embedding**。

## 定制文档（页签预留）

侧栏 **定制文档** 页签已预留。行业定制方案 / 报告 / 质量回顾等能力 **需按需开通**；未开通时页面会提示 **联系管理员进行定制开发**，无法生成或下载定制模板产物。
