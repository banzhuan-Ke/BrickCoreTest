# 测试目录

各测试模块（UI / 接口）共用同一套 **测试目录** 树，用于归类资产、侧栏筛选与项目级统计。

## 入口

**路径**：**项目配置 → 测试目录**

> 原「Web 自动化 → 测试目录」与独立的「接口分类 / 用例分类」已合并为本功能。

## 目录树管理

| 操作 | 说明 |
|------|------|
| 新建目录 | 侧栏树顶部 `+`，可指定上级目录 |
| 编辑 / 删除 | 悬停目录节点上的按钮 |
| 全部目录 | 选中后表格展示项目下所有目录 |

支持 **多级父子** 结构（如「知识库 → 场景知识库 → 解析管理」）。

## 统计与表格

页顶 **统计卡片**（随左侧选中范围变化）：

| 指标 | 说明 |
|------|------|
| 目录数 | 当前范围内的目录节点数 |
| 接口数 / 接口用例 | 挂在这些目录下的 API 资产 |
| UI 用例 / 套件数 | Web 自动化资产 |

表格列：目录名称、上级目录、接口数、用例数、套件数、UI 用例数；点击 **资产** 可查看该目录下关联套件列表。

## 在业务页中使用

### 列表页左侧树

以下页面左侧有 **目录树**，点击节点按 **子树** 过滤右侧列表（含子目录下数据）：

- **接口自动化**：接口管理、用例管理、套件管理、测试计划
- **Web 自动化**：用例管理、套件管理、执行计划

### 表单中的「所属目录」

新建/编辑用例、套件、计划时，使用 **树形下拉**（`CatalogTreeSelect`）选择目录，不再使用扁平下拉列表。

### 测试计划页汇总

**接口自动化 → 测试计划** 顶部展示计划数、条目数、并行/串行、累计执行、成功率、定时任务等汇总；表格含 **所属目录**、最近执行状态等列。

## 与项目、环境的关系

```
项目 → 环境（多套 Host/变量）
     → 测试目录（一棵树）
           → UI 用例 / 套件 / 计划
           → 接口 / 接口用例 / 套件 / 测试计划
```

目录 **不替代** 环境：执行时仍须选择环境；目录只影响组织与筛选。

## 常见问题

**Q：统计全是 0？**  
说明目录下尚未挂载资产。请在接口/用例/套件编辑页选择 **所属目录**；历史数据迁移后若未归类，需手工补选。

**Q：选父目录能筛到子目录下的用例吗？**  
可以。列表左侧树筛选默认 **包含子目录**。

**Q：删除目录会怎样？**  
目录软删除；子目录挂到被删节点的父级；原关联资产的 `catalog_id` 清空（变为未归类），不删除用例本身。

**Q：权限码还是 module:view？**  
是。角色权限中「测试目录」仍使用 `module:view` / `module:edit` 键名，与旧「模块管理」兼容。
