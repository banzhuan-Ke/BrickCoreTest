# BrickCore 使用文档

欢迎使用 **BrickCore** 一体化自动化测试平台。本文档按菜单结构说明各功能的操作步骤与常见问题。

## 平台能做什么

| 模块 | 用途 |
|------|------|
| Web 自动化 | Web 用例编排、录制回放、计划执行（需 **BrickCoreRunner**） |
| App 自动化 | Android 用例/套件/计划编排、元素库、元素探查；真机执行需 Runner 勾选 **App 自动化** |
| 接口自动化 | 接口管理、用例/套件/计划、Mock、定时执行、数据工厂 |
| 性能测试 | HTTP 压测、分布式 Worker、报告对比 |
| AI 测试 | 需求生成功能用例、测试分析、**智能浏览器**、失败分析、平台助手、**迭代资料库** |
| MCP 外部接入 | Kimi Code、Cursor 等 AI 客户端远程查询平台 |
| 数据看板 | 执行趋势、失败统计、定时任务待办 |

## 登录与顶部操作

1. 在浏览器中打开平台地址，使用管理员分配的账号登录
2. 顶部 **选择项目**：用例、接口、AI 数据归属当前项目
3. 顶部 **选择测试环境**（部分页面）：执行时可覆盖
4. 左侧菜单按业务分组展开

> 若看不到某菜单，请联系管理员在 **系统管理 → 角色权限** 中分配权限。

## 执行器（UI 自动化必备）

请按以下步骤安装执行器：

1. 从 [百度网盘](https://pan.baidu.com/s/1pObFpG-Mt7-Pxo58hklOlg?pwd=9gbi)（提取码 `9gbi`）或平台 **设备管理 → 网盘下载** 获取 `BrickCoreRunner.zip`
2. 解压后运行 `BrickCoreRunner.exe`，登录并 **上线** 设备
3. 详见 [执行器使用说明](guide/runner-client.md)、[执行器获取与发布](guide/runner-packaging.md)

## 建议使用顺序

| 步骤 | 做什么 | 文档章节 |
|------|--------|----------|
| 1 | 了解平台亮点 | 亮点功能 |
| 2 | 查看版本更新 | 版本更新记录 |
| 3 | 了解菜单与流程 | 平台概览 |
| 4 | 创建项目、环境、测试目录 | 项目与环境、测试目录 |
| 5 | 安装执行器（做 UI 时） | 执行器使用说明 |
| 6 | 进入 UI / 接口 / AI / 性能 | 功能模块（Web 录制见 **Web 录制与稳定回放**） |
| 7 | 配置报告推送（可选） | 系统管理 |
